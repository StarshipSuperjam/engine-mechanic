# Q24 + Q27 #2 re-litigation: the attention ranking-function form (ordered partition + weighted) and the scent threshold home

*Decided 2026-05-29 in the design workspace.*

## The decision

Resolve [Q24](#) (standalone `core`-lock blocker) and [Q27](../reference/open-questions.md) **instance #2** by re-litigating the locked [attention](../spec/systems/cognitive/attention.md) doc (the fourth locked-doc step of the closure wave, [D-112](0112-author-the-core-lock-closure-procedure-the-q24-q27-remediati.md)). **(Q24) The ranking-function form is pinned: an ordered partition with weighted intra-partition ranking** — candidates partition into the five budget categories (blocking debt · in-flight work · recent decisions · structural neighbors · orientation) under **hard cross-category precedence**, so "blocking debt ahead of features" is guaranteed by the structure (never weight-dependent); the **ranking weights** order candidates *within* each partition; the budget allocation is the partition slice-sizing. This is the only form under which both the doc's "ranking weights" and its lexicographic ordering rules hold at once, resolving the internal tension the dry-run flagged. It stays **deterministic, no ML/decay**, recency an intra-partition weight over the explicit as-of timestamp. The partition guarantees *ordering*, not category *membership*: whether a candidate is tracked debt is telemetry's promotion decision, and which open debt is *blocking* is attention's own debt-blocking rule — so the build-session fixture must test partition **assignment**, not only weights. **(Q27 #2) The per-prompt scent's strong-match threshold is homed in the attention policy** (the scent is attention at a tiny budget), sparing a [boot](../spec/systems/lifecycle/boot.md) alarm. The Build-spec-leaves section is narrowed: the form is pinned, only the concrete values (splits, weights, precedence order, trim, thresholds incl. the scent threshold) remain leaves. Two stale "boot/telemetry are `designed`" parentheticals are corrected to current truth (both now locked). Litigation-alarm re-litigation of the locked attention doc ([D-083](0083-re-litigate-attention-honesty-clarification-reference-time-a.md)), operator-approved this session; re-locked. `core`'s ranking-tool *body* realizing this form lands in the Phase-2 `core` reconciliation. **Q24 is deleted; [Q27](../reference/open-questions.md) instance #2 closes (Q27 stays open for #4/#5, both at the telemetry step).**

## Why

[D-110](0110-run-the-genesis-dry-run-through-complete-core-log-the-build.md)'s genesis dry-run found the combining form unowned — a builder could not resolve "ranking weights" (weighted sum) vs "unblocked first; blocking debt ahead of features" (lexicographic). Ordered-partition + weighted-intra is the synthesis (hard precedence between categories, weights within) and the **trust-safe** choice: the property a non-engineer relies on (blocking debt first) is structural, not a weight someone must calibrate correctly. The complete form is pinned now (operator-directed; the meta-convention [D-113](0113-core-lock-closure-phase-0-the-build-spec-leaf-form-contract.md) requires pinning the form and deferring the values; widening the leaf to defer the form again was rejected). A **focused cold re-audit** (two independent lenses + a confirmation pass) ran on the as-edited doc: the lenses **disagreed** on a key point and the adversarial lens caught a **blocking self-contradiction** — a first draft attributed "which candidate counts as blocking debt" to telemetry's "severity classification," contradicting the doc's own debt-blocking rule (blocking-ness is attention's; telemetry owns only promotion / what becomes tracked debt). Reworked so membership rests correctly on telemetry's promotion (is it debt) **and** attention's debt-blocking rule (is that debt blocking); a confirmation re-audit verified consistency with the debt-blocking bullet and the telemetry seam. Two nits folded: the coined "severity classification" removed, the two now-redundant deferral parentheticals tightened. **Propagation re-examined, no further edit owed:** [engine-architecture.md](../architecture.md) summarizes attention as "policy + deterministic ranking function" (still truthful — the form is a refinement below that altitude); the [glossary](../reference/glossary.md) `Attention`/`Scent` terms sit above combining-form granularity; [R4](../reference/risks.md) (attention hardcoded-constants) stays **open** (pinning the form is necessary-not-sufficient; it closes only when the build-session fixture calibrates the values — the doc's "right things first is unproven until the fixture" stands); `core` provides/wiring already lists the attention policy + ranking tool (the body realization defers to Phase 2). `python3 lock.py --relock systems/cognitive/attention/README.md --decision D-117`; `python3 validate.py` green.

## What we ruled out

**Weighted sum** (rejected — a miscalibrated weight could float a feature above blocking debt; the safety property must be structural for a non-engineer). **Pure lexicographic tiers** (rejected — "ranking weights" become near-vestigial and the ordering is rigid; the partition+weights form uses both). **Widen the attention build-spec leaf to defer the form** (rejected — contradicts the [D-113](0113-core-lock-closure-phase-0-the-build-spec-leaf-form-contract.md) meta-convention to pin the form, and `core` must ship a working ranking body). Home the scent threshold in **boot** (rejected — the scent is attention at a tiny budget; homing it in the attention policy spares a boot alarm, and boot pins no threshold value). Attribute **blocking-debt membership to telemetry** (rejected on re-audit — the doc's own debt-blocking rule makes blocking-ness attention's; telemetry owns only promotion). Close **R4** (rejected — pinning the form is necessary-not-sufficient; R4 awaits the calibration fixture). Delete **Q27** (rejected — instances #4/#5 remain).

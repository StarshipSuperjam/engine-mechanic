# Resolve the D-205 offline-cache-committer pin: landed-text cold audit, state + audits re-locked

*Decided 2026-06-17 in the design workspace.*

## The decision

The [D-205](0205-authorize-pinning-the-offline-cache-committer-the-audit-dige.md) change-set is landed and **re-locked**. The mandatory landed-text cold audit ran with four independent no-shared-context lenses (adversarial · technical-feasibility · non-engineer-operator · architect) on the as-written edits in [state](../spec/systems/cognitive/state.md) and [audits](../spec/systems/guardrails/audits.md) plus the carriers ([glossary](../reference/glossary.md), [risks](../reference/risks.md) [R23](../reference/risks.md)). **Outcome: technical-feasibility and architect PASS clean; one non-engineer-operator serious finding folded; one adversarial serious finding ground-truthed and REJECTED; the inline-history nit folded.** Re-lock set: **2**.

  **The audit + dispositions.**
  - **Technical-feasibility — PASS (no blocking/serious).** Ground-truthed against `origin/main` (mid-M1, memory slice 3a): the audit-digest committing workflow genuinely **does not exist yet** (only `engine-ci.yml`/`engine-guard.yml`, both `contents: read`, non-committing), and the as-written text is **honestly future-tense at every load-bearing point** ("the concrete wiring lands with the audit-library build") — it asserts no mechanism that exists today. The refresh primitives the eventual workflow will call already exist and are **non-committing by construction** (`telemetry.refresh_state`/`refresh_standing` write the cache file, never commit; `standing_situation.derive_standing_situation` is a pure injectable leaf). The committed `state.json` is still the junk hand-seed, confirming the re-seed is a real, separate, still-pending build task. The "digest-writing PR's required check passes" sentence is **pre-existing** (the digest's in-workflow regenerate-then-gate), not a new overclaim the freight introduces.
  - **Architect — PASS (no blocking/serious); all six verify-no-edit dispositions CONFIRMED.** [telemetry](../spec/systems/guardrails/telemetry.md) (the shared pass binds to telemetry's already-asserted **debt-register ownership**; telemetry already disclaims committing — "Telemetry itself commits no report"; no clause owed), [boot](../spec/systems/lifecycle/boot.md) (unchanged — derives for display, reads cache offline; the commit is out-of-band on the audit PR, not a boot event), the [audit-library](../spec/modules/audit-library.md) module doc + [modules/README](../reference/module-catalog.md) (genuine freight on an existing pass — no new `provides`/`wires`/deps, so the propagation matrix owes nothing), [scenarios/build-session](../architecture.md#build-session-lifecycle) · [scenarios/routine-session](../architecture.md#routine-session) · [scenarios/first-run](../architecture.md#first-run-provisioning) (none walks an offline-degraded boot read or a digest run that names a cache refresher/committer, so none is now stale), and [engine-architecture](../architecture.md) (pure role+link index, far below this altitude). **[§16](../principles.md) is correctly realized** — "the values are telemetry's and boot's, relayed as freight; the workflow carries no detection of the cache's content" is the integrator-relays / owner-detects law, with the persona-read-only / workflow-commits split intact.
  - **Non-engineer-operator — one serious folded.** The **"not-vouched" requirement landed silent**: the §16 freight mechanic was present at the design layer, but no operator-facing instruction directed the digest PR to mark the cache file as auto-derived / not-operator-vouched, so a build session had nowhere to learn it (dropped, not deferred). **Folded** into [audits](../spec/systems/guardrails/audits.md): the digest pull request presents the cache file as auto-derived freight the operator does not vouch for — the merge attests to the self-attestation it rides, not the cursor's contents (the plain-language wording a build-spec leaf under the operator-communication law). **Preserved (verified):** the `as-of` marker travels with the value by construction (state's "Pointers and counts only" rendering law + the glossary "same `as-of`/'may be stale' provenance" + "both fields together, never split"); the re-seed-as-trust-floor is carried in [D-205](0205-authorize-pinning-the-offline-cache-committer-the-audit-dige.md)'s build-side scope, correctly absent from the always-current design docs. **No §12 jargon leak** in the new operator-facing text (freight / schema-gated-not-drift-gated / GitHub-derived-cache-pass stay backstage; the operator gets the *consequence* — the staleness label — not the mechanism).
  - **Adversarial — one serious REJECTED (ground-truthed), one nit folded.** **Rejected (logged):** the claim that the freight commit creates a *second committed observational artifact* contradicting [telemetry](../spec/systems/guardrails/telemetry.md)'s "the **one** committed, human-readable observational artifact is the audit digest" (lines 150–152). Ground-truthed by reading telemetry's "Output home" section: that sentence is scoped to **telemetry's own outputs** and to the **tier-4 "observational" authority class** (the digest, "a derived, fingerprint-gated snapshot"); the `state.json` cache is **[state](../spec/systems/cognitive/state.md)'s cursor file** (a different authority class), committed by the audit *workflow* as freight — "Telemetry itself commits no report" stays literally true, and the engine already commits multiple derived artifacts (self-map, knowledge graph, digest), so the sentence was never a global-uniqueness claim. The architect lens independently reached the same verify-no-edit verdict. **Folded (nit):** the state body phrase "the committer deferred at D-198/D-199, now pinned" narrated a state transition (authoring-rule 1); tightened to a current-state statement (the committer named, the wiring deferred to the audit-library build, no deferred→pinned arc). **Logged-accepted:** the `(#100)` reference and `state/README` line 29's "refreshed by telemetry" are design-only / pre-existing and reconcilable, no edit owed; the `state-cursor` schema check being a real validators-core suite member is a build-spec confirmation.

  **Folds applied before re-lock:** [state](../spec/systems/cognitive/state.md) (inline-history tighten), [audits](../spec/systems/guardrails/audits.md) (the not-vouched operator-presentation instruction).

  **Re-lock set (2):** [state](../spec/systems/cognitive/state.md), [audits](../spec/systems/guardrails/audits.md). **Re-lock:** `python3 lock.py --relock` run on both under this decision; `python3 validate.py` green. **Carriers edited (non-locked):** [glossary](../reference/glossary.md) (*Standing-situation pointer* — committer named), [risks](../reference/risks.md) [R23](../reference/risks.md) (reframed: committer pinned, concrete wiring deferred; not closed). **Verify-no-edit (logged):** [telemetry](../spec/systems/guardrails/telemetry.md), [boot](../spec/systems/lifecycle/boot.md), [audit-library](../spec/modules/audit-library.md), [modules/README](../reference/module-catalog.md), [scenarios/build-session](../architecture.md#build-session-lifecycle), [scenarios/routine-session](../architecture.md#routine-session), [scenarios/first-run](../architecture.md#first-run-provisioning), [engine-architecture](../architecture.md), [build-orchestration](../spec/systems/lifecycle/build-orchestration.md). **No [open-questions.md](../reference/open-questions.md) opened/resolved; no [deviations](../reference/prototype-deviations.md) entry.** Still **42 docs locked** (2 re-locked, none added). **Build-owes (engine-template, downstream):** the **re-seed** of the committed `state.json` (junk `phase` note → null or a genuine derive output; honest `integration_debt`) is independently actionable now; the **committer wiring** (the audit-digest workflow refreshes + commits the shared cache as freight) lands with the post-M1 [audit-library](../spec/modules/audit-library.md) build, carrying the operator-honesty requirements (the `as-of` travels with the value; the cache reads in its PR as not-operator-vouched).

## Why

The lock gate requires a landed-text cold audit with every blocking/serious finding resolved before re-lock; it ran (four lenses), the technical-feasibility and architect lenses passed clean, the operator's not-vouched requirement was folded so it cannot be dropped at build, and the adversarial "second observational artifact" finding was ground-truthed against telemetry's actual text and rejected as an over-read (the sentence is scoped to telemetry's tier-4 observational output, not a global-uniqueness claim; the cache is state's cursor file committed by the workflow as freight). The landed text is faithful to [D-205](0205-authorize-pinning-the-offline-cache-committer-the-audit-dige.md): the refresh owner is unchanged, the siblings are not split, the audit *workflow* (not the read-only persona) is the committer, the cache is schema-gated not drift-gated, a missed cron only ages the labelled offline copy, and the concrete wiring is honestly deferred to the post-M1 audit-library build.

## What we ruled out

**Re-lock without the landed-text audit** (rejected — HARD lock gate). **Edit [telemetry](../spec/systems/guardrails/telemetry.md) to reconcile the "one committed observational artifact" sentence** (rejected — ground-truthed as a non-contradiction: the sentence is scoped to telemetry's own tier-4 observational output, the cache is a different authority class committed by the workflow as freight; an edit would manufacture a change the text does not require, against [R6](../reference/risks.md)). **Carry the not-vouched requirement only in [D-205](0205-authorize-pinning-the-offline-cache-committer-the-audit-dige.md) and not in the design doc** (rejected — a requirement that lives only in the log is invisible to the build session reading [audits](../spec/systems/guardrails/audits.md); the design-level instruction belongs in the doc, the exact wording a build-spec leaf). **Treat the inline-history phrase as an acceptable decision cite** (rejected — "deferred … now pinned" narrates a state transition, which authoring-rule 1 forbids even when the bare cite would be fine).

# Resolve Q7 (v1 skill membership); close deviation D2; the WBS deviation-gate clears

*Decided 2026-05-27 in the design workspace.*

## The decision

Resolve [Q7](../reference/open-questions.md) — the v1 skill *membership* across the [D-055](0055-collapse-command-into-the-skill-surface-invocation-is-a-gove.md) `invocation` axis — and thereby close the last `OPEN` deviation verdict ([D2](../reference/prototype-deviations.md)), the named gate on WBS authoring. The v1 roster is **four `operator-typed` skills and zero `model-auto`, zero `model-only`**: the **Build-entry verb** (`core`, [D-070](0070-lock-the-modes-system-wave-3-head-three-stances-on-two-axes.md)/[D-073](0073-lock-build-orchestration-wave-3-terminal-and-re-litigate-con.md)); **`engine-design`** (`product-design`, optional, [D-065](0065-product-design-front-door-design-the-q14-intake-module-as-a.md)); **`/engine-help`** (`core`, new) — a discovery index that **derives its listing by presence** ([§14](../principles.md)) so it shows only installed verbs (required modules always; an optional verb shown as "available if you install X"); and **`/engine-routine`** (`routine-mode`, required, new) — the routine-entry command embedded in a Local Desktop routine's Instructions, a thin entry (no step list) delegating to a named routine-entry [operation](../spec/systems/surfaces/operations.md) (the procedure home that preserves the drift-firewall), which enters the routine procedure whose entry authority is the operator-configured schedule + the build-Issue scope-lock (the modes/build-orchestration re-litigation that names it is [D-088](0088-justified-re-litigation-name-the-routine-entry-command-engin.md)). Discoverability (the committed requirement) is met by `/engine-help` **and** the operator orientation [doc](../spec/systems/surfaces/docs.md), which points to `/engine-help` rather than enumerating, so the two paths cannot disagree. `/engine-routine` is engine-prefixed per the [D-020](0020-engine-instance-identifiers-are-engine-namespaced-decision-r.md) identifier law; "routine" is retained as the operator-facing Claude Desktop *feature* name, not an exposure of the internal Routine *stance* vocabulary ([skills](../spec/systems/surfaces/skills.md) leak-guard).

## Why

Membership, not laws — the [D-055](0055-collapse-command-into-the-skill-surface-invocation-is-a-gove.md) grammar fixes the axis and the earns-a-skill bar; Q7 only fixes which instances ship. **Zero `model-auto` is earned, not asserted:** the prototype's auto-invoked skills now live as other surfaces — `review`/`security-review` → the [design-review](../spec/modules/design-review.md)/[qa-review](../spec/modules/qa-review.md) agent lenses ([D-066](0066-the-4-4-review-lens-roster-two-stage-suites-mirroring-the-en.md)); `build-readiness-gate` → the orchestration's plan-review gate; `frontend-discipline` → `check` rules / a future V&V lens ([D-068](0068-q1-resolved-the-v1-optional-module-roster-4-cut-2-kept.md)); `session-build-lifecycle`/`session-shutdown-sequence`/`ship` → [build-orchestration](../spec/systems/lifecycle/build-orchestration.md) + the close Stop-ritual ([D-072](0072-lock-the-close-system-wave-3-the-turn-stop-ritual-honest-tie.md)); ADR/contract capture is triggered by the build/close flow at the contract-threshold gate, **not** a model "reach" — no metacognition gap a resident skill serves, so no candidate clears the bar. `operator-typed` is rationed by **discoverability**, not attention, so four typed verbs cost no standing context. **The routine-entry command belongs in the roster** because a Local Desktop routine *firing* only launches a prompt; the activation is an embedded command — **validated empirically** against the live Paideia + engine-template scheduled routines whose Instructions body is literally a routine-entry slash command, invoked via the slash-command parser path (this overturned an earlier doc-based feasibility error that a cold-audit technical lens had carried). Propagation per the matrix: [open-questions.md](../reference/open-questions.md) Q7 deleted; [deviations/README.md](../reference/prototype-deviations.md) D2 → DECIDED; [systems/surfaces/skills/README.md](../spec/systems/surfaces/skills.md) line-77 Q7 citation repointed to this decision and the resolved `model-only`-none membership stated (a citation/membership edit, **no grammar-law change**; re-locked under this decision); `core` + `routine-mode` stubs record their provided commands; wbs/README.md gate-note. The routine-entry re-litigation of [modes](../spec/systems/lifecycle/modes.md) + [build-orchestration](../spec/systems/lifecycle/build-orchestration.md) is the separate [D-088](0088-justified-re-litigation-name-the-routine-entry-command-engin.md). A four-lens cold-context audit (adversarial / architect / non-engineer-operator / technical, the technical lens ground-truthing against the live files) ran against the plan; its blocking findings (route the command to an owned `operation` not a design-doc section; frame entry authority as the schedule + frozen scope-lock rather than a "stance signal" the model sets; an operator-visible durable misfire artifact) are discharged here and in [D-088](0088-justified-re-litigation-name-the-routine-entry-command-engin.md).

## What we ruled out

Carry the prototype's eight skills (rejected — each routes to its correct surface per the [D-042](0042-procedural-content-grounding-surface-cluster-designed-the-bo.md) boundary law: agents, hooks, or the orchestration/close flow; "skill" was the wrong home). Ship a `model-auto` ADR/contract-capture skill (rejected — capture is flow-triggered at the contract-threshold gate, no metacognition gap, no resident-attention cost justified). Ship any `model-only` skill (rejected — v1 need is none; the value stays reserved for additive future use, [D-055](0055-collapse-command-into-the-skill-surface-invocation-is-a-gove.md)). Drop the routine-entry command and treat firing as self-activating (rejected — empirically false; the live scheduled routine's Instructions body *is* the command, and modes clears the stance every `SessionStart`). Collapse the command directly onto a design-doc section with no procedure surface (rejected — loses the live drift-firewall; the thin command delegates to an owned `operation`). Pin `/start-routine` un-prefixed (rejected — violates the [D-020](0020-engine-instance-identifiers-are-engine-namespaced-decision-r.md) engine-prefix collision-reservation law; `/engine-routine` satisfies it).

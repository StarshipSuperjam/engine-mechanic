# Run the genesis dry-run through complete `core`; log the build-readiness blockers (Q24–Q27); secondary cross-doc-seam tuning

*Decided 2026-05-28 in the design workspace.*

## The decision

Ran the dry-run across the full pre-M1 genesis stretch — the L0 reference-root regression check, the stage-0 seed, and all eight `core` sub-slices (grammar+wiring, validation, state+attention, knowledge, guardrails+hooks, lifecycle, infra+foundation-infra, operator surfaces) — two-lens floor per producing step, then two independent cold adjudicators over the `core` findings. The full record is the scratch ledger wbs/dry-run-ledger.md. Outcome: **three genuine `core`-lock blockers** — the attention ranking-function *form* is unowned ([Q24](../reference/open-questions.md)); the telemetry promotion-threshold *policy instance* has no shipping owner ([Q25](../reference/open-questions.md)); the `/engine-help` (and module-kind) presence-discovery *mechanism* is unpinned ([Q26](../reference/open-questions.md)) — plus a **systemic serious meta-pattern**: `build-spec leaf` deferrals scoped to *values* while the *form/contract* is unpinned ([Q27](../reference/open-questions.md), covering the validation kind result-contract, the scent threshold owner, the knowledge-retrieval interface op-set, the telemetry finding-record shape + its missing Build-spec-leaves section, and the ambient-capture cache record). The stage-0 seed is structurally build-ready with three serious gaps clustered at the trust root (frozen check-name, PR-body non-emptiness predicate, section-matching contract — in the ledger). [Q22](../reference/open-questions.md)/[Q23](../reference/open-questions.md) are confirmed **genesis-only** (the deployed-instance path has no foundation-infra gap of its own). **Secondary tuning:** the builder brief gains a cross-doc-seam guard — a §16 detect/relay split whose owning doc pins the mechanism is `deferred`, not a gap — because both adjudicators found the builders over-tagged pinned cross-doc seams (close↔build-orchestration disposition channel, the routine halt-vs-continue verdict, the Build-entry referent) as gaps.

## Why

The operator canceled the `core` lock and the genesis-PR sequence precisely so the dry-run could surface the choices a premature lock would bake in; this run did, and the result **validates that call** — the three blockers and the meta-pattern are real deferred choices, and resolving most of them edits *locked* docs ([attention](../spec/systems/cognitive/attention.md), [policies](../spec/systems/surfaces/policies.md), [skills](../spec/systems/surfaces/skills.md)), i.e. litigation-alarm events that must not be silently frozen by a lock. The run stayed **read-only/advisory** per [D-108](0108-add-the-dry-run-build-simulation-instrument-the-workspace-s.md): no design doc was edited; the blockers and meta-pattern are logged as [Q24](../reference/open-questions.md)–[Q27](../reference/open-questions.md) (awaiting the operator's decision), not remediated. The stopping condition is met — **complete `core` reached, no intractable blocker** (every blocker is a resolvable design decision, not a dead-end). Calibration: the [D-109](0109-tune-the-dry-run-from-the-l0-calibration-a-deferred-disposit.md) reference-root fix held on the L0 re-run (zero findings, all leaves homed); a second over-tagging tendency — cross-doc §16 seams — was caught *entirely* by the reviewer lens, confirming the two-lens floor is load-bearing and the reviewer pass must not be dropped; the light builder-brief guard reduces that noise at the source while preserving "flag if the owning doc does not pin it." The core-A "serious" CODEOWNERS finding was a defect in this run's slice prompt (it listed a sixth seam outside the closed five-seam vocabulary), not a design gap — noted so future slice prompts feed the builder the correct vocabulary. Propagation: [open-questions.md](../reference/open-questions.md) Q24–Q27 added; wbs/dry-run.md builder brief refined; wbs/dry-run-ledger.md authored (a scratch artifact, not a canonical doc); this entry. `validate.py` green.

Lock `core` now (rejected — the operator canceled it for this reason; three blockers + a systemic pattern would be frozen in). Report only in chat / skip the ledger (rejected — finding-disposition forbids burying; the ledger is the durable build-readiness picture the operator asked the run to assemble).

# Lock the `attention` system (Wave-2): the policy-plus-function prioritizer, reads-never-owns

*Decided 2026-05-25 in the design workspace.*

## The decision

Ratify and lock [attention](../spec/systems/cognitive/attention.md) — the cognitive substrate's "what do I focus on, and at what level?" prioritizer — to its end-state: a **policy plus a function, not a store** ([D-010](0010-attention-is-a-first-class-surface.md) reconciled — *first-class* means its governing policy is a governed surface, not a new store of focus tokens). The two pieces are a committed, governed [policy](../spec/systems/surfaces/policies.md)-surface instance (budget allocation, ranking weights, trim order, the debt-**blocking** rule) and a **deterministic** ranking [tool](../spec/systems/surfaces/tools.md) (same inputs → same ordering; no scored-token store, no decay state, no ML) that **reads** [state](../spec/systems/cognitive/state.md), [knowledge](../spec/systems/cognitive/knowledge.md) adjacency, the [telemetry](../spec/systems/guardrails/telemetry.md) debt register, and the native git/GitHub work record, and produces the ordering + budget split. It governs **budget allocation**, **work prioritization** (ordering the native git/GitHub record — branches/PRs/Issues/Milestones — not a committed list, per [D-038](0038-session-lifecycle-re-founded-on-native-substrates.md)/[D-059](0059-lock-the-state-system-wave-2-head-the-committed-cursor-recon.md)), and **debt-blocking**. It **powers every [orientation](../spec/systems/lifecycle/boot.md) event** (cold start = large budget; the per-prompt scent = tiny budget + lexical trigger; "boot" is its heaviest invocation). The lock fixes six reconciliations to the designed doc: **(1)** the ranking inputs **drop "recent merged pull requests"** for "the native git/GitHub work record" — the recent-merged-PR *narrative digest* is [boot](../spec/systems/lifecycle/boot.md)'s "recently shipped" assembly, not an attention input (this would freeze a boot-owned detail), also fixing a doubled-word typo; **(2)** an explicit **pure deferral to boot** — the orientation *events* (which hook, what budget per event, the degraded-disclosure and plan-gate consent) are boot's to define; attention supplies the ranking and fixes none of boot's event model; **(3)** a new **"It reads; it never owns"** section — the anti-`FocusToken` guard ([D-029](0029-cognitive-substrate-is-one-workflow-a-2-store-1-register-1-c.md)/[principle §3](../principles.md)) made load-bearing, naming the read-not-own ownership split and an explicit pure deferral that **telemetry owns the debt-register shape**; **(4)** an **anchored honest-degradation hand-off** — when telemetry/GitHub is unreachable (outage or expired auth) or a substrate MCP is down, the function ranks over the remaining inputs (state's committed debt count **carried with its as-of marker** + local `git`) rather than failing, and the degraded-input set is handed to **boot**, which surfaces it loudly in plain language under its degradation-and-consent law ([D-059](0059-lock-the-state-system-wave-2-head-the-committed-cursor-recon.md) law 2, [principle §5](../principles.md)) — so a non-engineer is never shown a confident-looking but partial picture without the caveat; **(5)** the debt-**blocking** rule (which open debt gates the start of work) is distinguished from telemetry's debt-**promotion** thresholds (what a signal must clear to become tracked debt) — attention reads the register, it does not set those thresholds; **(6)** the doc's "Open questions" section becomes **"Build-spec leaves"** ([D-059](0059-lock-the-state-system-wave-2-head-the-committed-cursor-recon.md)/[D-060](0060-lock-the-knowledge-system-wave-2-the-purely-derived-structur.md)/[D-061](0061-lock-the-memory-system-wave-2-the-episodic-ledger-store-q3-b.md) precedent — a locked doc implies no unresolved *design*): the concrete allocation policy (splits, weights, trim order, debt-blocking threshold) + calibration inputs are the build-spec leaf, authored/fixture-tested in the build session, with the policies + tools grammar homes already locked. **No locked doc is edited** — a grep of all 19 locked docs confirms every "attention" reference is **consumer-only** ([state](../spec/systems/cognitive/state.md) "ordered by attention," [ontology](../spec/systems/grammar/ontology.md) "within the attention budget," [templates](../spec/systems/guardrails/templates.md) over-budget feed, [control-plane](../spec/systems/infrastructure/control-plane.md) PR-reviewer-attention metaphor, [policies](../spec/systems/surfaces/policies.md) surfaced-via-attention, [skills](../spec/systems/surfaces/skills.md) always-resident-description *attention cost*) — none defines attention's internals, so locking its end-state contradicts none and needs **no re-lock**. The mutual telemetry⇄attention deferral (telemetry: "the surfacing mechanism is attention's, not telemetry's"; attention: "telemetry owns the register shape") is a clean ownership split, not a circular dependency. **Q11** stays open (the representation/retrieval leaf stays swappable). This is the third Wave-2 system lock and the runway's penultimate cognitive lock; [boot](../spec/systems/lifecycle/boot.md) follows it.

## Why

Attention is the correct next [D-052](0052-foundational-law-layer-closed-the-implementation-lock-order.md) Wave-2 lock — after `state`/`knowledge`/`memory`, with `boot` last — and like `knowledge` it carried **no open design fork** (its lone open item was always a build-spec leaf), so it banks a clean advance. It anchors entirely on **locked** docs (state, knowledge, policies, tools, plus the topology/ontology grammar those sit on) and reduces its two `designed`-neighbor seams (telemetry, boot) to **pure deferrals** in the [D-053](0053-procedural-surfaces-reconciled-to-the-merged-claude-code-ski.md)/[D-056](0056-lock-the-tools-surface-wave-1.md)/[D-057](0057-lock-the-agents-surface-wave-1-four-settled-design-forks.md)/[D-059](0059-lock-the-state-system-wave-2-head-the-committed-cursor-recon.md) pattern, so neither neighbor's later lock can force an attention change. Most of the lock is *reconciliation, not invention*: [D-029](0029-cognitive-substrate-is-one-workflow-a-2-store-1-register-1-c.md)/[D-038](0038-session-lifecycle-re-founded-on-native-substrates.md)/[D-059](0059-lock-the-state-system-wave-2-head-the-committed-cursor-recon.md) had already moved candidate work and narrative to native substrates; the merged-PR-input and the implicit degradation gap were the residues. The four-lens cold-session design audit ([D-018](0018-cold-session-design-audit-required-before-any-lock.md): adversarial / technical-feasibility / non-engineer-operator / architect, no shared context) ran against the proposed design before this entry and returned **no real blocking findings** (the two "blocking" items were artifacts of a link-stripped review excerpt; the actual edit preserves all frontmatter and links); its serious findings were resolved into the lock: **(adversarial)** listing "recent merged pull requests" as an attention input risked freezing boot's recently-shipped digest → dropped for "the native git/GitHub work record"; **(non-engineer-operator)** the stale-debt-count fallback could reach the operator as a confident-but-partial picture → the degradation hand-off was anchored (as-of marker carried; boot's loud-disclosure law named on both ends), not merely punted; **(architect)** the `skills` "attention cost" seam is the closest consumer reference → named explicitly in this grep sentence as consumer-only, and the doc keeps skills-description cost **out** of its enumerated budget categories so the seam stays a pure deferral in both directions; the no-re-lock claim was grep-verified true and the propagation list confirmed **empty**. Technical-feasibility verified every platform fact (policy-as-schema-governed-data + function-as-`.engine/tools/`-code; the substrate reads via `gh`/MCP with the default token; the FTS5/BM25 per-prompt scent within a `UserPromptSubmit` latency budget; the heavy assembly at `SessionStart`; the state-committed-count read-fallback) against the locked neighbors and `constraints.md`, no blocking/serious. Propagation per the matrix: the corpus was already reconciled to attention's end-state — [glossary](../reference/glossary.md) (Attention/Debt register/Boot pack/Orientation/Scent/Lineage), [engine-architecture.md](../architecture.md) §4 table + prose, and the [remediation-loop scenario](../architecture.md#the-detect-to-remediate-loop) all already match and need **no edit**; **Risk [R4](../reference/risks.md) stays open** — it closes when the policy and function are *built*, and a lock is design ratification not a build (the [R2](../reference/risks.md)/[D-061](0061-lock-the-memory-system-wave-2-the-episodic-ledger-store-q3-b.md) precedent) — so this entry **firms R4, it does not close it**.

## What we ruled out

Keep "recent merged pull requests" as an attention ranking input (rejected — it freezes how `boot` assembles its recently-shipped digest, the lock-atop-a-churning-neighbour failure; attention ranks the open work record, boot owns the merged-PR narrative). Keep a `FocusToken`/`WorkingSet`/decay store (rejected — hand-authored mutable scored state violating [principle §3](../principles.md) and re-implementing the claim/scope/mode enforcement [modes](../spec/systems/lifecycle/modes.md) and [hooks](../spec/systems/infrastructure/hooks.md) already own; this is the prototype residue [D-029](0029-cognitive-substrate-is-one-workflow-a-2-store-1-register-1-c.md) fought). Leave the degradation hand-off as a bare "boot's job" (rejected — a developer-shaped punt could strand a non-engineer on a stale debt count with no caveat; the as-of marker + boot's loud-disclosure law are anchored on both ends, the operator-facing floor living in the law). Add a skills-description budget category to attention (rejected — it would convert a consumer *cost* into an attention-owned obligation and break the pure-deferral seam; skills' attention cost is something attention accounts for, not a category it allocates). Leave the "Open questions" section in the locked doc (rejected — a locked doc implying unresolved design is the drift the lock forbids; the build-spec-leaf restatement is the [D-059](0059-lock-the-state-system-wave-2-head-the-committed-cursor-recon.md)/[D-060](0060-lock-the-knowledge-system-wave-2-the-purely-derived-structur.md)/[D-061](0061-lock-the-memory-system-wave-2-the-episodic-ledger-store-q3-b.md) honest end-state). Edit or re-lock any locked doc (rejected — none constrains attention's internals; every reference is consumer-only, so locking attention's end-state contradicts none). Claim the lock closes [R4](../reference/risks.md) (rejected — R4 closes when the policy and function are built, not at design ratification). Defer the attention lock until boot or telemetry locks (rejected — attention is upstream of boot and reads telemetry's register through a pure deferral; locking it now fixes the ranking contract boot's later lock builds against).

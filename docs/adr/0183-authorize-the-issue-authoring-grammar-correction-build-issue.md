# Authorize the issue-authoring grammar correction (build issues #62/#63): pin the human issue-template sections + the engine-authored-issue body contract + the §13 follow-the-host rule (litigation alarm + authorization)

*Decided 2026-06-06 in the design workspace.*

## The decision

The locked [control-plane](../spec/systems/infrastructure/control-plane.md) ([D-017](0017-control-plane-locked-end-state-as-contracts-not-leaves.md); re-locked through [D-182](0182-resolve-the-d-181-scope-name-correction-landed-text-cold-aud.md)), [external-contribution](../spec/systems/lifecycle/external-contribution.md) ([D-121](0121-lock-the-external-contribution-system-doc-reconcile-the-stal.md)), and [modules/core](../spec/modules/core.md) ([D-136](0136-re-base-the-bootstrap-trust-model-on-a-sole-non-engineer-gat.md); re-locked through [D-180](0180-resolve-the-d-179-build-entry-augment-landed-text-cold-audit.md)) docs are **re-litigated** to close two design gaps the engine-template **build** surfaced (engine-template issues **#62**/**#63**, core slice 24). This entry is the **litigation alarm + authorization** (the operator authorized the audited change via plan-mode approval); the **edits + re-locks land under the resolve entry** [D-184](0184-resolve-the-d-183-issue-authoring-grammar-correction-landed.md) after the mandatory landed-text cold audit — the [D-181](0181-correct-the-non-existent-github-scope-admin-repo-ruleset-in.md)→[D-182](0182-resolve-the-d-181-scope-name-correction-landed-text-cold-aud.md) / [D-179](0179-augment-interactive-build-entry-with-plan-acceptance-correct.md)→[D-180](0180-resolve-the-d-179-build-entry-augment-landed-text-cold-audit.md) pattern.

  **The gaps (ground-truthed against the locked corpus).**
  - **#63 — human-facing issue templates** (`bug`/`feature`/`engine-fault`, the web "New issue" forms a *human* files): [control-plane](../spec/systems/infrastructure/control-plane.md) names them ("ship as lighter scaffolds") and says they travel, but **no WBS slice builds them** and their **required sections are pinned nowhere** — asymmetric with the PR template (whose sections *are* pinned in the same locked contract). AF-2's `templates`-surface mis-attribution is already corrected at [build-orchestration](../spec/systems/lifecycle/build-orchestration.md):377.
  - **#62 — engine-*authored* issue bodies** (created programmatically — telemetry findings, build Issues, audit findings, tracked debt — which **bypass** the web templates): control-plane owns the engine-domain **label** scheme but specifies **no body shape** and **no enforcement** (the PR side has the `pr-body-completeness` check, [validation](../spec/systems/guardrails/validation.md):120-122; the issue side has none) — the raw prose-dump failure (#59). And [external-contribution](../spec/systems/lifecycle/external-contribution.md) is **silent** on following an un-owned upstream's templates (a [§13](../principles.md) gap).

  **The verified platform facts (ground-truthed this session against current GitHub docs — the [§17](../principles.md) gold standard, not inference; version-brittle, so they live HERE + the build-spec leaf, NEVER in a locked doc — the [D-171](0171-correct-the-falsified-platform-ignores-a-pretooluse-deny-cla.md) discipline).**
  - `.github/ISSUE_TEMPLATE/` files are committed and **travel** via "Use this template" (like CODEOWNERS / the PR template).
  - Issue templates/forms populate **only** the web "New issue" form; the REST `POST …/issues` endpoint and `gh issue create` set the `body` **directly** and apply **no** template (established by the API surface carrying no template parameter + the standing ~3-yr open feature request, GitHub community discussion #4423 — there is no single docs sentence asserting it, so cite the durable evidence, not a quote). **Consequence:** a template file **cannot** constrain engine-authored issues; enforcement must be in the **authoring code**.
  - GitHub **cannot gate issue creation** with a required-check analog (rulesets target branches/tags/pushes only; even `blank_issues_enabled:false` is not enforced for direct creation, community discussion #14287). **Consequence:** there is **no merge gate** for issue bodies; the honest tier is by-construction-via-helper + posture.
  - A label set via API `labels` / `--label` applies at creation but is **silently dropped without push access** (a build-spec precondition the engine identity satisfies). The **"issue-template default" candidate at control-plane:245-246 is FALSE** for the engine's programmatic path — corrected here (A3).

  **The design (authorized; final text + landed-text audit land under [D-184](0184-resolve-the-d-183-issue-authoring-grammar-correction-landed.md)).** A four-lens cold **plan**-audit (adversarial · technical-feasibility — discharged by direct live GitHub verification · non-engineer-operator · architect, no shared context) ran before this authorization and reshaped it materially; its blocking/serious findings are folded below.
  - **A1 (#63).** Pin the human issue-template **required SECTIONS** (not copy) in control-plane, symmetric with the PR contract (the [D-122](0122-enumerate-the-branch-ruleset-protection-floor-in-control-pla.md) protection-floor-enumeration pattern); update the **"lighter scaffolds"** stale wording (pinned sections are no longer "lighter" — deletion mandate). `engine-fault` reframed to operator-**narration, not diagnosis** (the engine supplies the technical localization — the [audits](../spec/systems/guardrails/audits.md) escalate-upstream pattern, not a "where / how to reproduce" demand a non-engineer cannot answer). The section prompt **copy is a build-spec leaf** bound by the plain-language law, mandated plain (no "scope"/"environment"/"expected-vs-actual"/"acceptance"/"repro"/"surface"). Human templates are **markdown guidance, not enforced-required fields** ([QA-6](../reference/goals-and-quality.md) low-ceremony + the [D-141](0141-lock-product-design-the-design-front-door-the-fifth-module-l.md) anti-coercion spirit).
  - **A2 (#62).** The **engine-authored-issue body contract**, owned by control-plane as the [§16](../principles.md) channel definition, **bound to the engine-labeled channel** (every engine-authored issue carries it — *not* an ambiguous "self-monitoring/build/debt" sub-set, since a build Issue can *be* the spec Issue). A **loose structural skeleton** — in plain language: *what it is and why it is here* / *what (if anything) the operator must decide or what happens next* / *backstage references rendered as plain links, never an ID dump* — stated as the skeleton that telemetry's and audits' existing locked operator-contract language **fills** (the PR-contract precedent: control-plane owns the shape, the producer fills it, **truthfulness is posture**). The **product-design spec Issue is the §16 named exception declared owner-side** (its body is the [D-141](0141-lock-product-design-the-design-front-door-the-fifth-module-l.md) plain-prose spec + acceptance criteria — a body-*realization* difference, not a set-exclusion). **Honest tier:** no merge gate (GitHub cannot gate issue creation); well-formed **by construction** for any issue authored via the shared helper (the helper assembles the body from required call arguments), and authoring-*via*-the-helper is **posture** — low blast radius (a malformed self-monitoring body is a legibility degradation, never a guardrail weakening; [§15](../principles.md) n/a). **A1 and A2 are two distinct contracts** (human web-form templates vs. a producer-filled, code-enforced body shape).
  - **A3.** Fix the stale **"issue-template default"** label-application candidate at control-plane:245-246 (web-only; false for the programmatic path) → keep the two working mechanisms (explicit `labels` at creation; post-create label call) as the build-spec-leaf candidates.
  - **B (external-contribution).** The [§13](../principles.md) consequence: on an un-owned upstream the engine **follows the target repo's** PR template (+ CONTRIBUTING), and its issue templates **only if/when** it files an issue upstream (the contribution artifact is a PR, so the PR template governs); falls back to the engine's own shape only when the target has none. **Posture/narration only, no new wiring or check** — the upstream's own review is the honest backstop.
  - **C (modules/core).** `provides` gains the **issue-authoring helper** [tool](../spec/systems/surfaces/tools.md) (a passive [§14](../principles.md)/§16 formatter producers *call* — not a central registry they edit; one shape, not a shape-family); the **three issue-template files** join the **foundation-infrastructure-artifacts union** (modules/core:35-42, like CODEOWNERS + the ruleset-guard workflow), **not** `provides`. `wires` is **unchanged**.
  - **D (WBS, revisable).** Add a slice **shipping the human issue templates** (control-plane native, ownership-bound to core — the slice-15 PR-template pattern) + a slice **building the helper and routing all producers** (after slice 18, the first label producer; `owes ← 18` / `owes → 24`; reconcile slice 18's own apply path to avoid two issue-authoring paths). Add the missing roadmap pointer; reconcile module-order/dry-run if they enumerate the control-plane build order.
  - **E/F (revisable).** [glossary](../reference/glossary.md) gains *engine-authored-issue body contract*; [risks](../reference/risks.md) **R13** gains one upstream-template-following clause; [engine-architecture](../architecture.md):43 confirmed/edited for the truthful "PR/issue templates" index.

  **Carrier verification.** [telemetry](../spec/systems/guardrails/telemetry.md), [audits](../spec/systems/guardrails/audits.md), [product-design](../spec/modules/product-design.md), [build-orchestration](../spec/systems/lifecycle/build-orchestration.md) are **reconcile-and-verify** — the contract is declared **owner-side** (the §16 label-scheme pattern: consumers inherit by the owner's declaration, not by each re-pointing); each is verified for **non-contradiction** against the *loose* skeleton, and **joins the re-lock set only if** its locked language does not cleanly fill it (the [D-184](0184-resolve-the-d-183-issue-authoring-grammar-correction-landed.md) landed-text audit arbitrates; the watch item is audits' pinned plain-prose exemplar at :186-190). **Re-lock set as authorized (3):** control-plane, external-contribution, modules/core.

## Why

A locked trust contract that owns the human issue templates and the engine-labeled channel but specifies **no issue-authoring grammar** — leaving the engine free to drop raw prose-dump issues (#59) into a non-engineer's tracker, and the human templates unbuilt and section-less — is a direct hit on **trustworthiness** and **cold-start legibility**; and because the planning workspace is the eADR-canon transplant source, the gap would propagate into every deployed Engine. **Justified re-litigation, not drift** (the lock stops drift, not warranted edits — CLAUDE.md litigation alarm). It **completes a claim the locked doc's role implies but never wrote** — the [D-122](0122-enumerate-the-branch-ruleset-protection-floor-in-control-pla.md) / [D-181](0181-correct-the-non-existent-github-scope-admin-repo-ruleset-in.md) pattern. The dated, version-brittle platform facts stay in this log + the build-spec leaf (the [D-171](0171-correct-the-falsified-platform-ignores-a-pretooluse-deny-cla.md) discipline), only the durable grammar in the locked docs. The plan-audit reshaped the design before this authorization: it caught the helper-vs-untouched-producers contradiction (resolved: owner-side declaration + a passive call-based helper), the "self-monitoring/build/debt" unresolvable boundary (resolved: bind to the engine-labeled channel), the audits-exemplar-breaking rigid headers (resolved: loose skeleton), the engine-fault diagnosis-demand (resolved: narration + engine-supplied localization), the enforced-required-fields ceremony tax (resolved: markdown guidance), the `provides`-vs-foundation-infra mis-classification (resolved: union), the missed engine-architecture carrier, and the stale "issue-template default" candidate (A3) — all folded above.

## What we ruled out

**Build the templates/helper without pinning the grammar in the locked design** (rejected — #62/#63 explicitly route the design question to engine-planning; the build cannot invent the contract, and an unpinned grammar reproduces the every-feature-a-refactor failure [R5](../reference/risks.md)/[R6](../reference/risks.md) exist to prevent). **A standing validation check over engine-authored issue bodies** (rejected — issues are not merge-gated, by-construction-via-helper is the mechanism, and a standing validator is the telemetry-sprawl [R6](../reference/risks.md) rejects; revisit only on an observed producer bypass). **Mandate rigid four labeled headers** (rejected — would break audits' pinned plain-prose exemplar at :186-190 and read as an engineer's ticket; the skeleton is loose, rendered headings bound by the operator-communication law). **Scope the body contract to "self-monitoring/build/debt issues"** (rejected — a build Issue can *be* the spec Issue, so that sub-set is unresolvable; the boundary is the already-owned engine-labeled channel, with the spec Issue the §16 realization exception). **Make the human templates enforced-required fields** (rejected — blocks a non-engineer behind fields they do not understand; [QA-6](../reference/goals-and-quality.md) + the [D-141](0141-lock-product-design-the-design-front-door-the-fifth-module-l.md) anti-coercion spirit; markdown guidance instead). **Ask the operator to localize an engine fault ("where" / repro steps)** (rejected — assumes diagnostic skill the non-engineer lacks; the engine supplies localization, the audits escalate-upstream pattern). **Put the issue-template files in core `provides`** (rejected — `.github/` control-plane files ride the foundation-infrastructure-artifacts union by the locked grammar, like CODEOWNERS; modules/core:35-42). **Make the helper a central registry every producer edits to register** (rejected — anti-[§14](../principles.md); it is a passive formatter producers call, attaching additively). **Bake the version-brittle platform strings into the locked docs** (rejected — dated; the [D-171](0171-correct-the-falsified-platform-ignores-a-pretooluse-deny-cla.md) discipline keeps them in the log + build-spec leaf). **Edit the locked docs without the landed-text cold audit** (rejected — HARD lock gate; the audit + re-lock land under [D-184](0184-resolve-the-d-183-issue-authoring-grammar-correction-landed.md)).

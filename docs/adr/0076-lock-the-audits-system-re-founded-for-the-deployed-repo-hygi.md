# Lock the `audits` system, re-founded for the deployed-repo HYGIENE case; tuning deferred to a future optional module

*Decided 2026-05-26 in the design workspace.*

## The decision

Lock [audits](../spec/systems/guardrails/audits.md), re-founded from a **maintainer/template-authoring** stance to the **deployed-repo operational-hygiene** case it actually runs in. `audit-library` ships as a `required` module, so the cron runs inside deployed repos, where most Engine surface is **template-owned machinery** (overlaid on every update, so a local edit is wiped, and a core component can't be retired without breaking updates/integration). The audit therefore acts only on **accumulated local state** and the machinery/local line is **mechanical** (an artifact is machinery iff it is in an installed package's manifest `provides` set — the file-precise CODEOWNERS ownership; everything else in the engine corners is project-authored). **Two disposition lanes:** *local retire/reconcile* (ordinary Build work, merge = adjudication) and *escalate-upstream* (a machinery bug **drafts** a template-repo report the operator files via their own `gh` / forks / ignores — never auto-filed, never a silent phone-home; deduped by the same stable source-key so a recurrence updates one draft; degrade-and-disclose if the template repo is unreachable/private/issues-disabled/interaction-limited). Retirement-default is rescoped to local cruft only (machinery is never a retire-candidate; a quiet *shipped* artifact is an escalate-upstream signal). The three posture laws survive, reframed for local artifacts; law 1 carries **no quota** (a manufactured nomination is the failure; the honest no-candidates subsection is preferred). **Q12 resolved:** the concern-list growth bound is the **contract-threshold mechanism applied to concerns** — deliberate reviewed authorship (a row added only via a merged Build PR) + an entry bar (targets a drift the generic sweep misses, can't be a mechanical check, carries an affirmative case) + a schema presence gate (a `justification` field, validation-checkable) + **reflexive function-probe retirement** (the concern-list is itself an audit target; a fresh probe, never cached counts, retires rows now subsumed/mechanizable/never-well-formed); no numeric cap, no new policy, no telemetry stream. The **silent-stop** gap is closed by a **dated digest** whose staleness emits a finding [boot](../spec/systems/lifecycle/boot.md) surfaces through its locked open-findings path (naming the `gh workflow enable` re-arm action), plus boot rendering the dated digest as an informational digest — a boot build-spec leaf, **no boot re-lock**. The **maintainer systemic-architecture review is dropped entirely** (not shipped downstream; the maintainer runs it ad hoc against the template repo). `python3 lock.py systems/guardrails/audits/README.md --decision D-076`; ratified_by D-076. **Q12 is resolved and deleted from [open-questions.md](../reference/open-questions.md).**

## Why

The operator caught a **category error**: the D-041 design ("retire stale surfaces," "is this system earning its place," remediate via local Build PR) is maintainer-stance, but the audit runs in deployed repos where those targets are immutable template machinery — a machinery bug can't be locally PR'd (the overlay reverts it) and a core component can't be retired. We explored re-founding telemetry+audits as a full self-maintenance loop with **both hygiene and tuning** (CoALA procedural-memory learning; web-researched against CoALA §4.5 + the 2024–26 selective-forgetting/SSGM/Reflexion line). A **four-lens cold-session audit of that arc** converged hard against bundling tuning into core: tuning (a) is **infeasible as specified** (Claude Code exposes no "what-was-acted-on" signal; "acted on" is a semantic judgment telemetry's charter forbids), (b) **contradicts attention's locked determinism** ("no decay state, no machine learning"), (c) **can't be meaningfully consented to by a non-engineer**, and (d) **over-weights the contagious core** (§12). On that evidence the operator re-scoped to **hygiene now (core); tuning to a future optional module**. A **second four-lens cold-session audit of the assembled hygiene doc** then ran; its findings were all resolved before lock: **[blocking]** the local-vs-machinery line was not mechanically determinable for same-type surfaces (shipped vs project-authored policies/skills/agents) → fixed with the manifest-`provides` provenance discriminator; **[serious]** escalate-upstream lacked dedup → added (stable source-key); **[serious]** the 60-day cron fact was wrong ("push to default branch") → corrected to "no repository activity / a commit resets; default-branch governs execution, not the disable clock"; **[serious]** the ≥1-retire-candidate framing read as a quota → softened to no-quota; **[serious]** plain-language was only intent → made an exemplar-backed requirement with backstage vocabulary fenced; the boot-staleness lens split (architect: clean build-spec leaf; adversarial: overclaim) was resolved by grounding the wording in boot's locked open-findings path (the operator had already adjudicated the seam-deferral, no boot re-lock). Seam-checks confirmed no re-lock of policies (escalate-upstream is an additive elaboration), boot, validation (the `audit-prep` deferred trigger is *fulfilled*), or memory (the semantic memory-hygiene concern sits above memory's mechanical decay, no duplication). Propagation per the matrix: audits (locked end-state), this entry; [open-questions.md](../reference/open-questions.md) (Q12 deleted, deferred-tuning-module pointer added); [modules/audit-library/README.md](../spec/modules/audit-library.md) + [modules/README.md](../reference/module-catalog.md) (reconcile the pre-existing `default-on`→`required` drift, resolve its dangling Q12 ref, extend `provides`); [glossary.md](../reference/glossary.md) (escalate-upstream, the two disposition lanes, concern-entry; update Audits/Audit-digest); [risks.md](../reference/risks.md) R6 firmed by the Q12 bound + the deferred-tuning overfitting note; [scenarios/remediation-loop.md](../architecture.md#the-detect-to-remediate-loop) reconciled to the two-lane disposition; [engine-architecture.md](../architecture.md) role line verified truthful.

## What we ruled out

The **full hygiene+tuning self-maintenance arc with tuning in required core** (rejected on the arc cold-audit's converging evidence — infeasible signal, contradicts attention's determinism lock, non-engineer can't consent, §12 over-weight; tuning is deferred to a future optional module, on the roadmap not lost). **Ship the maintainer systemic-architecture-review posture to deployed repos** (rejected — deployed repos can't act on machinery findings; it is the maintainer's ad-hoc work against the template). **A numeric cap / new policy / telemetry stream for concern-list growth** (rejected — deliberate-authorship + reflexive function-probe retirement is the governor, matching contract-threshold). **Persona-judgment for the machinery/local line** (rejected — it must be mechanical via manifest `provides`, or the retirement-default would nominate quiet *shipped* artifacts into a churn loop the overlay restores). **A non-deduped or "fire-and-forget" escalate-upstream** (rejected — a recurring machinery mis-fit would re-nag every cron; it dedups on the same stable key, and "ignore" is framed as an honest informed choice, not a silent close). **Re-litigate boot for digest-staleness** (rejected — it fits boot's locked open-findings + informational-digest + staleness-shown laws as a build-spec leaf; the operator adjudicated the seam-deferral).

## Why

This completes the operator's chosen sweep over the 7 L2 + 2 L3 modules not covered by the genesis ([D-110](0110-run-the-genesis-dry-run-through-complete-core-log-the-build.md)) or L2 ([D-123](0123-run-the-l2-dry-run-validators-core-memory-substrate-both-bui.md)) runs, meeting the build-readiness **precondition** for the BUILD-READY modules' packaging locks (each still owes its own fresh cold-session audit + operator go). The sweep earned its cost: beyond confirming five modules build-ready, it surfaced **three cross-document gaps** invisible to a single-doc reader but fatal (or inconsistent) for a builder — **Q28** (the engine-label scheme owned by no living doc), **Q29** (the audit persona untypeable in the locked agents grammar), and the **depends-divergence** (a 3-way module-doc contradiction with an L3-vs-L2 consequence) — each ground-truthed against source and each the Q27-family "a contract/owner referenced but never pinned/coherent" shape the genesis run first named. The sweep applied a uniform **Q28 discriminator**: a module is Q28-blocked only when its OWN artifact directly reads/writes an engine-labeled Issue (product-design emits; github-projects-sync reads the debt count); a module that merely relays into the core finding-disposition/telemetry channel ([§16](../principles.md)) is touched-but-not-blocked — so the alarm is not multiplied across the ~8 consumers (one control-plane re-litigation unblocks all). Every reviewer was well-calibrated (no over-tagging); the one lens dissent of the sweep (the audit-persona "nit") was overturned by ground-truthing the locked agents text ([agents](../spec/systems/surfaces/agents.md):42 forbids the "carry no role" escape).

## What we ruled out

Lock the build-ready modules now (rejected — build-readiness is the precondition, not certification; each owes a cold audit + operator go). Multiply the Q28 alarm per consumer (rejected — one scheme, one control-plane fix). Treat the depends-divergence as **litigation** (rejected — all three docs are `designed`, so the remedy is a designed-doc reconciliation; no locked doc changes). Treat the depends-divergence as a mere **nit** (rejected — the reviewer upheld serious: a live 3-way contradiction with an L3-vs-L2 build-layer consequence, against the workspace's own target-axis discriminator). **Stop the sweep at the first litigation alarm** (rejected — the operator's standing direction was record-and-continue; completing the sweep mapped the full Q28 blast radius and surfaced Q29 + the depends-divergence, which a stop would have missed). **Fold Q29 / the depends-divergence into Q28** (rejected — three distinct gaps: an engine-label scheme [control-plane], an agent role/invocation grammar [agents], and a module dependency edge [designed module docs]; different owners, different remedies, two litigation vs one reconciliation).

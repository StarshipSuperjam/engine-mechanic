# Q27 #4 + #5 re-litigation: the telemetry finding-record + ambient-capture record shapes; Q27 closed

*Decided 2026-05-29 in the design workspace.*

## The decision

Resolve [Q27](../reference/open-questions.md) **instances #4 and #5** — the telemetry finding-record body shape (and its missing Build-spec-leaves section) and the ambient-capture cache record shape/path — by re-litigating the locked [telemetry](../spec/systems/guardrails/telemetry.md) doc (the fifth and final locked-doc step of the closure wave, [D-112](0112-author-the-core-lock-closure-procedure-the-q24-q27-remediati.md)). **(Q27 #4) The finding-record** extends the canonical [`finding.v1`](../spec/systems/surfaces/schemas.md) base ([D-113](0113-core-lock-closure-phase-0-the-build-spec-leaf-form-contract.md)) with telemetry's own markers — a **`source-id`** (the rule-id/surface-id/stream-id that keys the source-keyed dedup) and **first-seen/last-seen observation markers** (what auto-resolve reads to close a now-absent signal); the base `severity` is telemetry's per-consumer **severity class** (`trust-critical` | `persistent-but-benign`). A **Build-spec-leaves section** is added (the doc previously had none — the dry-run flagged its absence): the concrete finding-record + ambient-capture JSON Schemas, the cache path, and the stream-cache layout are values; the forms are pinned; the three promotion threshold *values* are **not** telemetry's leaf — they live in the triage-threshold [policy](../spec/systems/surfaces/policies.md) ([D-114](0114-q25-re-litigation-a-fourth-v1-core-policy-the-triage-thresho.md)) telemetry reads. **(Q27 #5) The ambient-capture cache record** shape `{rule-id, pass/fail, event-derived markers}` and path are pinned and **owned by telemetry**, with the [§16](../principles.md) seam named explicitly (the hooks `PostToolUse` writer conforms; **hooks registers no record shape, so no hooks edit is owed** — sparing an alarm); the record is **distinct from `finding.v1`** (a check-fire record, not a finding). Litigation-alarm re-litigation of the locked telemetry doc ([D-075](0075-lock-the-telemetry-system-guardrails-arc-head-the-triage-vol.md)), operator-approved this session; re-locked. **This closes Q27 entirely** (instances #1 [D-115](0115-q27-1-re-litigation-the-validation-kind-callable-result-cont.md), #2 [D-117](0117-q24-q27-2-re-litigation-the-attention-ranking-function-form.md), #3 [D-116](0116-q27-3-re-litigation-the-knowledge-retrieval-interface-operat.md), #4+#5 here) — **[Q27](../reference/open-questions.md) is deleted**. The telemetry detect→surface *machinery* bodies realizing these shapes ride `core`'s `provides` (the Phase-2 reconciliation).

## Why

[D-110](0110-run-the-genesis-dry-run-through-complete-core-log-the-build.md)'s genesis dry-run flagged the finding-record body unpinned, telemetry's Build-spec-leaves section absent, and the ambient-capture record unowned. The finding-record edit only *names* fields the locked doc already implied — `source-id` is the existing source-keyed dedup key (rule-id/surface-id/stream-id), the first/last-seen markers are what the locked auto-resolve already reads — applying [D-113](0113-core-lock-closure-phase-0-the-build-spec-leaf-form-contract.md)'s `finding.v1` cross-cut, so it introduces no new law. The ambient record is the §16 sibling of [D-117](0117-q24-q27-2-re-litigation-the-attention-ranking-function-form.md)'s boot/attention split and [D-116](0116-q27-3-re-litigation-the-knowledge-retrieval-interface-operat.md)'s knowledge/memory split: detection+mechanism with the owner (telemetry), relay at the integrator (the hooks `PostToolUse` writer) — the closure procedure's [D-112](0112-author-the-core-lock-closure-procedure-the-q24-q27-remediati.md) step-6/7 coordination resolved to a single owner (telemetry), so hooks stays untouched. A **focused cold re-audit** (two independent lenses) ran on the as-edited doc before re-lock: both cleared it (the finding-record coheres with the other `finding.v1` consumers — check severity = `tier`, agents severity = `blocking|serious|nit`, telemetry severity = severity class — per-consumer enums over one base; the §16 ambient seam agrees with the locked hooks split; the Build-spec-leaves section correctly defers values and attributes the three thresholds to the [D-114](0114-q25-re-litigation-a-fourth-v1-core-policy-the-triage-thresho.md) policy; Q27's five instances are all genuinely closed with no stranded `[Q27]` citation in any locked/living doc). One nit folded: the severity-class token aligned to the doc's canonical `persistent-but-benign`. **Propagation:** the [glossary](../reference/glossary.md) `finding.v1` term already names telemetry's finding-record extension (no update owed); no engine-architecture/risks edit (R4's threshold-home is the [D-114](0114-q25-re-litigation-a-fourth-v1-core-policy-the-triage-thresho.md) policy's, unchanged here); `core` provides ships the detect→surface machinery, the shape bodies deferring to Phase 2. `python3 lock.py --relock systems/guardrails/telemetry/README.md --decision D-118`; `python3 validate.py` green.

## What we ruled out

Edit **hooks** to home the ambient-record shape (rejected — §16: telemetry owns the channel's record, the hook relays; hooks pins no record shape, so no hooks edit/alarm is owed). Make the **ambient record a `finding.v1`** (rejected — it is a check-fire record, a signal source, not a surfaced finding; conflating them muddies the dedup/promotion seam). Give the finding-record a **fresh severity enum** (rejected — [D-113](0113-core-lock-closure-phase-0-the-build-spec-leaf-form-contract.md) fixed severity as a per-consumer enum; telemetry's axis is its severity class). Pin the **threshold values** in telemetry's Build-spec leaves (rejected — they live in the triage-threshold policy [D-114](0114-q25-re-litigation-a-fourth-v1-core-policy-the-triage-thresho.md); telemetry reads them). Pin the concrete **JSON Schemas** now (rejected — build-spec values; pin the form, defer the values, [D-113](0113-core-lock-closure-phase-0-the-build-spec-leaf-form-contract.md)). Keep [Q27](../reference/open-questions.md) open (rejected — all five instances now closed; the umbrella is deleted).

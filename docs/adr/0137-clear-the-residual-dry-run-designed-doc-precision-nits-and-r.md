# Clear the residual dry-run designed-doc precision nits and remove the now-empty module Status sections (pre-lock cleanup; supersedes D-131's slim-to-pointer convention)

*Decided 2026-05-30 in the design workspace.*

## The decision

Clear the residual designed-doc nits the dry-run sweep flagged but never remediated — pre-lock cleanup before the module packaging-lock passes begin, so each lock lands on a clean, current doc (the operator's chosen sequencing). **Four precision/clarity nits, each on a `designed`/revisable doc, no locked doc touched:** **(1)** [external-contribution](../spec/modules/external-contribution.md):33 — the upstream-clean nudge declared "the pre-submission / `pre-close` suite", but `pre-submission` is a build-orchestration *gate*, not one of the four self-declarable validation suites (pre-commit/pre-close/CI/audit-prep, [validation](../spec/systems/guardrails/validation.md):67-72); reduced to **`pre-close`** only. **(2)** [product-design](../spec/modules/product-design.md):80 — its authoring-time "criteria-quality verdict" shared verbatim phrasing with [design-review](../spec/modules/design-review.md):42's plan-review-gate verdict; added a one-clause **[§16](../principles.md) cross-reference** marking the two as distinct moments of one concern, not a duplicated obligation. **(3)** [modules/README.md](../reference/module-catalog.md):112 — "absorbed by the qa-review lenses + the `retroactive` lens" could read as if [qa-review](../spec/modules/qa-review.md) *provides* `retroactive`; clarified it is a **separate post-merge lens, not part of the pre-submission quartet** (an additive lens a future module may ship, [agents](../spec/systems/surfaces/agents.md):52). **(4)** [audit-library](../spec/modules/audit-library.md):26 — the `depends: validators-core` edge was justified only "per the catalog"; replaced with the substantive **floor-present** rationale (the semantic self-audit presupposes the mechanical self-validation floor held, [validators-core](../spec/modules/validators-core.md):83) — a real presence assertion, the `depends` *value* unchanged. **Plus the pre-lock Status-section cleanup:** the `## Status` section is **removed entirely** from the eight module docs that still carried one ([validators-core](../spec/modules/validators-core.md), [memory-substrate-sqlite-fts5](../spec/modules/memory-substrate-sqlite-fts5.md), [routine-mode](../spec/modules/routine-mode.md), [audit-library](../spec/modules/audit-library.md), [external-contribution](../spec/modules/external-contribution.md), [github-projects-sync](../spec/modules/github-projects-sync.md), [migration-discipline](../spec/modules/migration-discipline.md), [dependency-discipline](../spec/modules/dependency-discipline.md)) — **superseding [D-131](0131-slim-module-status-sections-to-one-line-pointers-the-prose-s.md)'s slim-to-a-one-line-pointer convention and reversing its delete-vs-slim anti-choice.** The reversal is licensed by a changed fact: D-131 kept a one-line pointer because two of the eight carried a *non-derivable* "blocked pending [Q28](#)/[Q29](#)" signal worth preserving in-doc; once [D-132](0132-own-the-engine-label-scheme-in-control-plane-re-litigation-r.md)/[D-133](0133-type-the-cron-fired-audit-persona-re-litigate-agents-role-tr.md)/[D-135](0135-re-verify-the-three-d-132-d-133-unblocked-modules-resolve-gi.md) resolved every block, the section reduced to pure restatement of state owned authoritatively elsewhere (dry-run ledger, locks.yaml, the frontmatter `status:` field) — the hand-authored derivative [principles §2/§3](../principles.md) and the deletion mandate forbid — and these docs are entering lock-prep, where the convention removes the Status section anyway ([D-120](0120-lock-core-the-root-module-the-closure-wave-s-terminal-ratifi.md)/`core` precedent). End state: **all eleven module docs are uniformly Status-section-free**, which also closes the [D-130](0130-reconcile-every-designed-module-status-section-to-current-tr.md) "flagged, not done" consistency gap (design-review/qa-review/product-design never carried a Status section).

## Why

These four nits are the residue of the dry-run sweep after its three *serious* designed-doc items were already remediated — [routine-mode](../spec/modules/routine-mode.md):42 stance-marker framing ([D-128](0128-reconcile-routine-mode-s-stance-marker-framing-to-d-088-the.md)), the [dependency-discipline](../spec/modules/dependency-discipline.md) depends-divergence ([D-129](0129-reconcile-dependency-discipline-to-depends-core-l2-the-targe.md)), and the [github-projects-sync](../spec/modules/github-projects-sync.md) board-config home ([D-135](0135-re-verify-the-three-d-132-d-133-unblocked-modules-resolve-gi.md)) — so this pass is the low-stakes tail the operator chose to clear before the packaging locks. Per the audit-the-plan discipline **graded to substance** (the [D-130](0130-reconcile-every-designed-module-status-section-to-current-tr.md)/[D-131](0131-slim-module-status-sections-to-one-line-pointers-the-prose-s.md) reconciliation-sweep precedent, not the lock-grade four-lens gate — these are editorial precision fixes on revisable docs touching no locked doc), a **proportionate two-lens cold-context check** ran against the completed edits: a **propagation-completeness** lens and a **faithfulness** lens, both independent and cold. Faithfulness returned all five edits clean (it confirmed `pre-close` is a real suite and `pre-submission` is not, the §16 split is genuine, the `retroactive` and floor-present framings match the design, and the Status removals dropped no live signal and left clean markdown). Propagation returned one **[serious]** — the Status *removal* deviates from [D-131](0131-slim-module-status-sections-to-one-line-pointers-the-prose-s.md)'s slim-not-delete choice and must be logged as an explicit supersession with its rationale, not as routine nit-clearing — **folded** (the Decision now records the supersession and the changed fact that licenses it) — plus a **[nit]** that the removal closes the [D-130](0130-reconcile-every-designed-module-status-section-to-current-tr.md) consistency gap — **folded**. **Propagation per the matrix:** the four nit docs + [modules/README.md](../reference/module-catalog.md) + the eight Status removals (all `designed`/revisable); this entry; and a single **"Resolved by D-137"** annotation appended to the frozen dry-run ledger (no verdict rewritten). **Verified no-change with rationale (logged, not silent):** **no catalog/dependency-graph propagation is owed** — nit (4) changed audit-library's `depends` *rationale prose*, not its *value* (the [modules/README.md](../reference/module-catalog.md) graph edge `validators-core → audit-library` and the catalog row are unchanged); [glossary.md](../reference/glossary.md) (no term touched), [engine-architecture.md](../architecture.md) (indexes systems, not per-module nit-state), [risks.md](../reference/risks.md) (no risk cites these nits), [open-questions.md](../reference/open-questions.md) (these were ledger nits, never open questions). `python3 validate.py` green (71 docs, no errors); **lock fingerprints unchanged** — every edited path cross-checked against locks.yaml (the only locked `modules/` path is `modules/core`, untouched).

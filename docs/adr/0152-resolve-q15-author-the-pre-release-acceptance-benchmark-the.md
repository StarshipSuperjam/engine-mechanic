# Resolve Q15: author the pre-release acceptance benchmark (the third build-readiness instrument)

*Decided 2026-05-30 in the design workspace.*

## The decision

Resolve [Q15](../reference/open-questions.md) by authoring wbs/acceptance-benchmark.md — the maintainer-layer, workspace-process **pre-release efficacy instrument**, the third and last construction gate after the dry-run (design buildable, pre-build) and build-conformance (built code vs spec, per-PR): it runs the **assembled, running engine** against expert-labeled fixtures and real non-engineer observation to prove it delivers before the v1 template is published. **Posture (operator-decided): an evidence-to-maintainer gate** — it produces a per-gate evidence bundle the maintainer gates publication on, may consciously release with a *named, logged* sub-bar gate, but never ships silently below bar ([§17](../principles.md): informed consent on evidence, never an automated bar a non-engineer cannot weigh). This resolves the canon split (Q15's "release gate for v1" vs [risks.md](../reference/risks.md)'s "optional Q15 release-gate benchmark") toward a **committed v1 pre-release gate**. The instrument fixes the **five acceptance gates** the cognitive-substrate efficacy scorecard ([D-085](0085-record-the-cognitive-substrate-efficacy-scorecard-exercise-w.md)) named: **G1** attention orientation/ranking fixture (expert-labeled, partition + intra-partition scoring, a determinism re-run on frozen inputs *including the as-of timestamp*, an independent-labeler/distinct-scorer anti-bias split — discharging [R4](../reference/risks.md)'s "calibrated against the fixture" closure); **G2** memory/scent retrieval-quality evals (recall@k/precision@k over a labeled set, the scent threshold set by an empirical precision/silence sweep, paraphrase pairs as a *diagnostic* of the lexical floor's synonymy weakness, **not** a bar it must clear); **G3** the M3 longitudinal **recoverability** test (a rarely-cued record stays *findable* — memory's recoverability-not-ranking guarantee, [D-081](0081-re-litigate-memory-ledger-write-integrity-law-reframe-usage.md) — explicitly **not** a test of, nor a contradiction with, attention's locked determinism); **G4** the K3 gap-recall test (100%-required, scoped to the *detectable structural-gap class* the knowledge-coverage + validation mechanisms surface, so the total bar is meaningful); **G5** the operator-perception battery on true non-engineers incl. first-timers (S6b/B9b/M9b/M13/S3b/B11b), procedure fixed in-doc, subject counts/recruitment/named-populations left as the maintainer's closures. **Fixture-before-weights** (weights fit the fixture, never the reverse — [D-083](0083-re-litigate-attention-honesty-clarification-reference-time-a.md)'s authoring-order recommendation, homed here) is tiered honestly as a build-process posture with a named [R16](../reference/risks.md)-class ceiling (the benchmark cannot mechanically detect post-hoc gaming). The instrument doc is technical (maintainer-layer); its **output is plain-language consequence** per gate (the build-conformance §6 discipline), the operator never meeting "G4"/"recall@k" ([§12](../principles.md)). The only fixed bar is G4 = 100%; the rest are build-spec leaves (values only — forms pinned). **Propagation:** the new wbs/acceptance-benchmark.md + [Q15](../reference/open-questions.md) deleted from open-questions + [Q31](../reference/open-questions.md)'s inline Q15 reference re-pointed to the resolved home + wbs/README.md (Q15 dropped from the residual-questions line; the benchmark added as the third instrument) + a [glossary.md](../reference/glossary.md) "Acceptance benchmark" entry (a cross-corpus term, mirroring the Build-conformance review entry) + [risks.md](../reference/risks.md) R14's Q15 reference reconciled ("optional" dropped, pointed at the now-authored instrument; R4's own fixture-closure condition is untouched) + this entry. **No edit owed** to [engine-architecture.md](../architecture.md) (it indexes the build *sequence* and a genesis *scenario*, not the dry-run/build-conformance *instruments* — adding this workspace-process tool there would breach the established pattern and layer discipline), README.md (a one-line `wbs/` group description, no per-instrument enumeration), CLAUDE.md (a `wbs/` sub-doc, not a top-level doc/systems-group; reachable via wbs/README.md + the log), or any locked doc. The append-only log's file-level `[Q15](../reference/open-questions.md)` links (D-046/D-083/D-085) stay valid (they link the file, not the deleted anchor). `python3 validate.py` green.

## Why

Q15 was the one open question the design's completeness could not retire by reasoning — the workspace had a sound, buildable, faithfully-buildable design but no empirical proof the engine *delivers*. D-085 had already sharpened the five gates but explicitly left the benchmark unbuilt; authoring it as a `wbs/` instrument is the natural completion, mirroring the dry-run and build-conformance siblings in shape, layer, reversibility, and advisory-to-the-human-gate posture. The evidence-to-maintainer posture (over a hard automated all-gates bar) is the §17 default: the sole non-engineer maintainer must be able to weigh the verdict, and a mechanical gate the non-engineer cannot override would invert that. Each gate was grounded against the system it probes so the benchmark tests what those systems actually claim — G3 against memory's recoverability (not attention's determinism), G4 against the detectable structural-gap class (so 100% is achievable and meaningful), G2's paraphrase pairs as a diagnostic (not a lexical-floor failure) — and fixture-before-weights was tiered as posture with a named ceiling rather than dressed as enforcement, per §7. It is workspace-process, fenced from the Engine-design docs per layer discipline, so it costs no locked-doc edit and no engine-architecture index entry.

## What we ruled out

**A hard, all-gates-must-pass automated release gate** (rejected — §17: a mechanical bar the non-engineer cannot weigh or override inverts the one-trust-gate model; the operator chose evidence-to-maintainer). **Keep Q15 a post-v1 optional instrument** (risks.md's "optional" framing) (rejected — the operator committed it as the v1 pre-release gate; shipping v1 with no empirical efficacy proof is the gap Q15 names). **Author the instrument but leave Q15 open** (rejected — a complete instrument *is* the resolution; an open question whose deliverable exists is stale, the deletion mandate). **Index the benchmark in [engine-architecture.md](../architecture.md)** (rejected — the dry-run and build-conformance instruments are not indexed there; that master indexes the Engine end-state + build sequence, and a workspace-process tool there breaches layer discipline). **Allow remediation by tuning weights to the fixture** (rejected — that games the benchmark; remediation fixes the engine and re-runs, the fixture-before-weights discipline). **Test G3 as attention behavior** (rejected — it would manufacture a contradiction with attention's locked determinism; the decay-risk is memory's frecency-ranked recall, which memory owns, so G3 tests memory's recoverability guarantee).

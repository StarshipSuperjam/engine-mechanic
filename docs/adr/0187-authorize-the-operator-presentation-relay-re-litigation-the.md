# Authorize the operator-presentation relay re-litigation: the AI's chat is the sole in-session operator channel (engine-template #83)

*Decided 2026-06-08 in the design workspace.*

## The decision

Authorize a re-litigation editing five locked docs + the framing docs to fix a live-verified platform gap surfaced by engine-template **#83**: the deployed Engine **cannot show the operator any formatted content**. A behavioral test in the operator's own client (temporary hooks, observed and torn down) confirmed that **no Claude Code hook output channel reaches the operator's screen** — `additionalContext` and plain `stdout` are model-only, `systemMessage` is documented-but-field-unreliable (observed invisible), and `permissionDecisionReason`/stderr are not reliably shown (corroborated by the four-lens technical lens against current docs + issues #17356/#50542, and by the operator's lived experience that he has *never* seen engine content except when the AI typed it). **The AI's own chat message is the sole in-session operator channel.** Consequently the whole boot pack (status card, governance alarms, degraded notices, reversible-forgetting readout, recently-shipped digest), the build risk-assessment, the [modes](../spec/systems/lifecycle/modes.md) blocked-action notice, and the [close](../spec/systems/lifecycle/close.md)-gate prompt all reach only the model, and the locked floor's present-marker check ("look for the Project status card") is **inert** (the card never renders). This is a platform **quirk** (may change in a future version), **not** a design law.

  **The settled design (operator-converged, audit-refined) — the [operator-presentation relay](../reference/glossary.md):** the quirk defined once in [constraints](../reference/constraints.md) (version-contingent), the convention once in [glossary](../reference/glossary.md), **referenced** by the producers (never a new principle).
  - **Injected content is AI-facing** — the boot pack is the AI's *briefing* ("you received this; the operator cannot see it; use it to help them"), with an **imperative relay marker** (*"INFORM THE USER THAT…"*) on the must-push subset — the operator's load-bearing **asymmetry** insight: the AI does not otherwise know the operator is blind to the injection. The AI keeps **full** grounding (the pack stays complete).
  - **Push the safety-critical, pull the routine.** Governance alarms + a grounding-failure tell are pushed every session (imperative); routine status is pulled on demand via a **new model-auto [status verb](../reference/glossary.md)** (operator-typed AND AI-offered/run, read-only) rendering a user-facing dashboard — the injected pack and the verb output being two renderings of the same data in different tones.
  - **Present-marker re-anchored** from "look for the card" to **a named orientation block the AI renders FIRST every session** (an alarm, or a one-line all-clear carrying the named token); its absence from the AI's opening is the binary "did-not-ground" signal — a presence check decidable by a non-engineer, now realized by relay.
  - **Per-surface conversational relay:** the build risk-assessment is the AI *explaining* what it will change / why these reviews / cost ([build-orchestration](../spec/systems/lifecycle/build-orchestration.md)); blocked actions are plain conversational ([modes](../spec/systems/lifecycle/modes.md)); the close-gate prompt + summary are conversational but **emphatic** so they are not dropped ([close](../spec/systems/lifecycle/close.md)).
  - **Honest tier:** relay is **posture** ([§6/§7/§17](../principles.md)) — the platform offers nothing stronger; the protected-branch merge backstops governance, and a skipped governance relay shows as a missing present-marker.

  **The fresh four-lens cold design audit ran (on the *broadened* design; the earlier audit saw only the narrow boot-card version) and its blocking/serious findings were resolved before authoring:** (1) the first present-marker re-anchor ("notice the absence of an orientation line") was unreliable → replaced with the **named-token-first** binary presence check above (adversarial + non-engineer lenses converged); (2) the §16 "who detects a skipped relay" gap → resolved by naming the §17 bound (a skipped relay is model-internal, unobservable to any substrate; governance is protected by the present-marker + the merge wall; the residual is non-critical pull content) rather than an infeasible telemetry detector; (3) routine-but-important state hidden behind the verb → push now carries a brief "needs-attention" headline (AI judgment over the full pack), pull carries the detail; (4) imperative-marker firehose → markers **reserved** for the must-push set; (5) "the AI might forget" framing → operator copy foregrounds the merge wall as the real guarantee. The technical lens independently re-verified every channel fact (the relay-only foundation holds).

  **Scope.** Re-lock (locked): [boot](../spec/systems/lifecycle/boot.md), [modes](../spec/systems/lifecycle/modes.md), [close](../spec/systems/lifecycle/close.md), [build-orchestration](../spec/systems/lifecycle/build-orchestration.md), [modules/core](../spec/modules/core.md). Edit (non-locked): [constraints](../reference/constraints.md), [glossary](../reference/glossary.md), [risks](../reference/risks.md) ([R19](../reference/risks.md)). Verified-no-edit (logged): [hooks](../spec/systems/infrastructure/hooks.md) (operator-visibility already routes via the PR Validation section + boot relay; "a guardrail only an AI reads is advisory theatre" already embodies the litigation), [control-plane](../spec/systems/infrastructure/control-plane.md) + [telemetry](../spec/systems/guardrails/telemetry.md) (own detection/contract; "the operator sees" is *realized* by the relay, not falsified), [engine-architecture](../architecture.md) (push framed "in front of the model" — truthful index), attention, scenarios. The engine-template **#83** build realization is a downstream follow-up, not authored here.

## Why

The litigation-alarm protocol authorizes a locked-doc change on explicit operator approval; the operator authorized the full execution after the live test settled the decisive fact and the design converged in dialogue. The gap is real (the operator has *never* seen engine-produced content except via the AI), the fix is forced by the platform (no other channel exists), and it is framed honestly — a version-contingent quirk plus a posture-tier relay, never over-promised. The cross-cutting scope is justified (every operator-facing producer rides the one quirk) and bounded to the producers plus the two anchor docs.

## What we ruled out

**`systemMessage` / plain `stdout` as the operator channel** (rejected — live-tested invisible + field-unreliable, #50542/#17356). **A new principle for the relay** (rejected — it is a platform quirk that may evaporate in a future version; principles.md is for durable laws; constraints.md already homes version-contingent platform facts, e.g. the compact-source injection). **The dashboard as pull-only** (rejected — safety-critical alarms a user might never pull would be missed; they must be pushed). **A telemetry "skipped-relay" detector** (rejected — a skipped relay is model-internal and unobservable to a hook; the present-marker + merge wall are the feasible mitigations). **The status verb as scope-creep** (rejected — it is the *only* operator-reaching path for routine status; without it that half of the gap stays unfixed). **constraints.md as the wrong home for a version-contingent fact** (rejected — it already holds such facts; the contingency is stated inline). **Keep the original "first thing you SEE is a card" present-marker** (rejected — the card never renders, so the check is inert; it must move to the relay's named-first block).

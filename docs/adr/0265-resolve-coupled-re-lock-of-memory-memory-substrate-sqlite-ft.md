# Resolve: coupled re-lock of `memory` + `memory-substrate-sqlite-fts5` (the retained pre-migration snapshot tag + migration-revert restore mode) — the carriers of D-264

*Decided 2026-06-27 in the design workspace.*

## The decision

Coupled re-lock of [memory](../spec/systems/cognitive/memory.md) and its packaging bundle [memory-substrate-sqlite-fts5](../spec/modules/memory-substrate-sqlite-fts5.md), the carriers of [D-264](0264-authorize-git-native-retention-for-the-pre-migration-memory.md) (the [D-049](0049-re-lock-topology-and-module-system-file-precise-codeowners-o.md) coupled-relock precedent: two locked docs that carry one contract, one semantic event). The landed text — memory's "One mechanism, two consumers — with a retained pre-migration snapshot" + "one plain action" bullets and floor (2), and the bundle's `provides` cell + "Backup, restore, and the migration unit" section — passed its mandatory **landed-text cold audit** (the irreversible-relock gate, CLAUDE.md) before this re-lock. **The four-lens audit** (faithfulness/propagation · architect/seam · adversarial+feasibility · non-engineer-operator, no shared context): **no blocking on any lens.** Faithfulness — all eight [D-264](0264-authorize-git-native-retention-for-the-pre-migration-memory.md) mechanism laws + three operator floors landed faithfully, authored-complete (no changelog cruft), internally consistent with the locked Compaction↔provisioning ordering law and the generation-stamp resurrection-surfacing, links clean. Architect/seam — ownership single-mastered (mechanism + restore contract in memory, the bundle its packaging), **no hidden third re-lock** (provisioning, boot, migration-discipline confirmed verify-no-edit against the landed text — boot's generic open-findings renderer carries the snapshot-vs-HEAD target and the missing-snapshot finding as *content*, within its locked wording/content split; provisioning names no target ref so reads true unchanged), scope minimal (completes the [D-048](0048-provisioning-delivery-designed-end-state-brownfield-capable.md) promise, R6-clean). Adversarial+feasibility — every platform fact ground-truthed against current GitHub/git docs and **confirmed accurate** (private-repo tag-protection / rulesets / Immutable-Releases are paid-tier; a `refs/tags` ref travels on default clone/fetch where a custom ref does not; the Contents-API 100 MB / `.raw`-above-1 MB limits); the worst-case erasure sequence (snapshot@genN → erasure-compaction@genN+1 → revert) **surfaces** the resurrection via the generation guard rather than silently resurrecting — consistent with the detect-and-disclose posture, not a backdoor.

  **Two serious operator-trust findings (convergent with the adversarial leak nit), both folded in-line** (the [D-242](0242-resolve-the-d-241-audit-memory-read-enablement-the-landed-fo.md)/[D-253](0253-resolve-re-lock-control-plane-the-review-record-carries-the.md) fold-before-relock practice): **(S1)** the operator-facing restore command risked showing a raw `refs/tags/…` string → the "one plain action" bullet now guarantees the snapshot is named by a **plain handle** ("the copy saved before the last update"), the operator never reading or typing the tag name or any `refs/…` string; **(S2)** floor (2)'s committed vault-README said "don't delete a snapshot tag," assuming git knowledge the operator lacks → recentred on the redirect in folder/file terms ("don't delete anything in here — even items that look old or unused are restore points; ask the Engine"), the mechanism word "tag" removed from the operator-facing README content. **Nits folded:** the missing-snapshot finding now names an **honest recovery action** (the clean one-step undo is gone, so the Engine re-runs the update or the operator asks for help — floor (4) applied), the update-moment disclosure says the copy was saved **automatically with nothing to do now**, and the collision-naming clause names the **migration id** as the guarantee (timestamp only secondary). **A focused operator-lens remediation re-check** ran on the folded text: **S1 and S2 RESOLVED**, no new leak, one residual plain-language nit (the "re-matches code to data" framing) folded out. `python3 lock.py --relock systems/cognitive/memory/README.md --decision D-265`; `python3 lock.py --relock modules/memory-substrate-sqlite-fts5/README.md --decision D-265`; the non-locked propagation ([scenarios/upgrade-the-engine.md](../architecture.md#upgrading-the-engine), [glossary.md](../reference/glossary.md) *Migration snapshot* term, [risks.md](../reference/risks.md) R2 disk-growth residual + R7 touch) landed; `python3 validate.py` green. The verify-no-edit dispositions [D-264](0264-authorize-git-native-retention-for-the-pre-migration-memory.md) recorded stand unchanged.

## Why

memory and its bundle both carry the restore-contract text, so they re-lock together as one semantic event ([D-049](0049-re-lock-topology-and-module-system-file-precise-codeowners-o.md)); the authorize→resolve-after-landed-text-audit split ([D-262](0262-authorize-the-disposition-issue-resolution-check-a-17-7-mech.md)/[D-263](0263-resolve-re-lock-validators-core-the-disposition-issue-resolu.md)) kept the irreversible coupled re-lock behind its own clean gate. The audit earned its keep: the convergent operator+adversarial finding caught that the trust surface risked leaking a raw ref string and assuming git knowledge — both folded to plain handles / a folder-level redirect before the lock, so the [§17](../principles.md) burden-of-proof posture holds (the non-engineer meets "the copy saved before the last update," never the machinery). The platform-fact re-verification confirmed the "distinct retained tag, not platform immutability" framing is honest on the default free vault.

## What we ruled out

**Re-lock memory and the bundle under separate decisions** (rejected — they carry one contract, so one coupled entry per [D-049](0049-re-lock-topology-and-module-system-file-precise-codeowners-o.md) is the honest unit; separate ids would imply two semantic events). **Promise platform-enforced tag immutability** (rejected at audit — unavailable on the default free private vault; the distinct-ref structure is the tier-independent guarantee, hardening disclosed as optional). **Leave the operator-facing tag string as-is** (rejected — a raw ref reaching a non-engineer is the [§7](../principles.md)/[§12](../principles.md) leak the repo's premise forbids; folded to a plain handle). **Re-lock provisioning / boot** (rejected — each consumes the widened contract and names no restore target; verify-no-edit confirmed against the landed text).

# Authorize pinning the offline-cache committer: the audit-digest pass commits the shared `state.json` cache as freight (completes the D-198/D-199 deferred committer)

*Decided 2026-06-17 in the design workspace.*

## The decision

Authorize a re-litigation (litigation alarm) on explicit operator approval that lightly edits locked docs to **pin the committer** for [state](../spec/systems/cognitive/state.md)'s offline cache. **The litigation alarm:** the operator observed that `state.json` in the engine-template build reads stale and orphaned — frozen on a hand-seeded value, with nothing keeping it fresh. Investigation confirmed the **demotion is correct and already honest** ([D-198](0198-authorize-correcting-100-where-we-are-is-assembled-read-only.md)/[D-199](0199-resolve-the-d-198-standing-situation-correction-landed-text.md) made "where we are" a live read-only [boot](../spec/systems/lifecycle/boot.md) derive, with `state.json` the best-effort offline cache — no reframe owed), but surfaced a real gap: [D-198](0198-authorize-correcting-100-where-we-are-is-assembled-read-only.md)/[D-199](0199-resolve-the-d-198-standing-situation-correction-landed-text.md) settled the cache's **refresh owner** (*"the same GitHub-derived-cache pass that refreshes the debt count"*, both fields together by [state](../spec/systems/cognitive/state.md)'s locked sibling invariant — "refreshed best-effort from the same source as the debt count") and explicitly **rejected** moving cache-refresh onto telemetry-as-design-responsibility, deferring the *wiring* to the build as "build-owes" — **but never named what *commits* that pass's output to the protected branch.** Every candidate committer is barred by a locked law ([telemetry](../spec/systems/guardrails/telemetry.md)'s "exactly one write" is issues-only; [boot](../spec/systems/lifecycle/boot.md) is read-only; the [audits](../spec/systems/guardrails/audits.md) persona is read-only; [build-orchestration](../spec/systems/lifecycle/build-orchestration.md) was decoupled from the cursor by [D-198](0198-authorize-correcting-100-where-we-are-is-assembled-read-only.md)), so the build had **no legal actor** to assign — the deferred "build-owes" had no buildable target.

  **The decision — pin the committer = the audit-digest pass (the audit *workflow*, not the read-only persona).** Both cache fields ride the audit's already-committed, periodic, operator-reviewed self-attestation PR **as freight** — a separate committed file gated by its own [`state-cursor` schema check](../spec/systems/cognitive/state.md), **never folded into the digest's fingerprint gate**. This completes the committer [D-198](0198-authorize-correcting-100-where-we-are-is-assembled-read-only.md)/[D-199](0199-resolve-the-d-198-standing-situation-correction-landed-text.md) deferred without changing the refresh owner, which stays the shared GitHub-derived-cache pass (composing [telemetry](../spec/systems/guardrails/telemetry.md)'s debt-count derive + [boot](../spec/systems/lifecycle/boot.md)'s standing-situation derive); **the siblings are not split.** Three bounds are named, not hidden: **(1) schema-gated, not drift-gated — and that is correct, not a hole** (the cache derives from continuously-changing *external* GitHub state, so "in sync" is undefined and a fingerprint gate would be incoherent; its guards are the schema check + the staleness label, [principles §3](../principles.md)); **(2) a missed audit cron is not a silent no-op** (it only *ages* the offline fallback, which renders stale-labelled — it never corrupts the *online* read, which [boot](../spec/systems/lifecycle/boot.md) derives live — categorically unlike #100, where a no-op corrupted the online card; preserves [D-199](0199-resolve-the-d-198-standing-situation-correction-landed-text.md) fidelity); **(3) the concrete wiring is deferred to the [audit-library](../spec/modules/audit-library.md) build (post-M1)**, where the digest workflow exists — pinning the principle now leaves the correct breadcrumb per the "decide grammar early" charter without pretending the mechanism exists yet.

  **Reshaped by a four-lens cold plan-audit.** A first design — assign the **audits system** to refresh-and-commit the cache — was killed: the audit-digest pass is part of the **unbuilt post-M1** [audit-library](../spec/modules/audit-library.md) module (the build is mid-M1, memory slice 3a), so "ride the *existing* pass" was false against the build; the framing was **false to the [D-198](0198-authorize-correcting-100-where-we-are-is-assembled-read-only.md)/[D-199](0199-resolve-the-d-198-standing-situation-correction-landed-text.md) record** (the refresh owner was already settled, not an open gap); it **split the locked sibling fields** (standing-situation → audit cron, debt count → "same pass"); and loading a status-cursor commit onto the **judgment** system repeated the very *"relay dressed as ownership"* category error [D-198](0198-authorize-correcting-100-where-we-are-is-assembled-read-only.md) just removed from [build-orchestration](../spec/systems/lifecycle/build-orchestration.md). The reshaped decision rides the existing committed pass **as freight** (the **workflow**, not the read-only persona, [principles §16](../principles.md)), keeps the siblings together, and defers the wiring.

  **Scope.** **Locked edits — 2:** [state](../spec/systems/cognitive/state.md) (PRIMARY — the "Seams are deferrals" clause + the cache description name the committer, the schema-gated-not-drift-gated bound, and the cron-miss-≠-silent-no-op fidelity; the sibling invariant stays explicit), [audits](../spec/systems/guardrails/audits.md) (light — the audit-digest **workflow** also carries the refreshed `state.json` cache in its committed digest PR; the **persona stays read-only**; the cache is schema-gated, outside the digest's fingerprint gate). **Verify-or-light (decided at the landed-text audit, minimize per [R6](../reference/risks.md)):** [telemetry](../spec/systems/guardrails/telemetry.md) (owns the debt *derive*, not a committed-cache write — expect verify-no-edit once state carries the seam), [boot](../spec/systems/lifecycle/boot.md) (derives for display, reads cache offline — unchanged, expect verify-no-edit), the [audit-library](../spec/modules/audit-library.md) module doc / [modules/README](../reference/module-catalog.md) (freight on an existing pass → expect verify-no-edit, disposition logged), scenarios/ (build-session · routine-session · first-run — check the offline-degraded boot / digest-run walks; edit-or-verify, logged), [engine-architecture](../architecture.md) (expect verify-no-edit). **Carriers (non-locked):** [glossary](../reference/glossary.md) (*Standing-situation pointer* / *State* — name the committer), [risks](../reference/risks.md) [R23](../reference/risks.md) ("build-unwired today" → "committer pinned to the audit-digest pass; concrete wiring deferred to the audit-library build" — reframe, do not close). **Build side:** **re-seed** `state.json` to a conforming value now (junk `phase` note → null or a genuine derive output; honest `integration_debt`) — independently actionable, so the junk note does not persist behind the post-M1 wiring; the **committer wiring** is tracked against the [audit-library](../spec/modules/audit-library.md) build. The re-locks land under the **Resolve** entry ([D-206](0206-resolve-the-d-205-offline-cache-committer-pin-landed-text-co.md)) after the mandatory landed-text cold audit.

## Why

The litigation-alarm protocol authorizes a locked-doc change on explicit operator approval. [D-198](0198-authorize-correcting-100-where-we-are-is-assembled-read-only.md)/[D-199](0199-resolve-the-d-198-standing-situation-correction-landed-text.md) deferred the committer to "build-owes" but left **no legal actor** (every candidate barred by a locked law), so the build could not conform — naming the deferred committer is the minimal close. The audit-digest pass is the **one existing committed, periodic, operator-reviewed self-attestation**; the cache rides it **as freight**, so no new autonomous committer is introduced (the engine's first standalone scheduled-commit actor is avoided), the [audits](../spec/systems/guardrails/audits.md) read-only persona law is preserved (the **workflow** commits, not the persona), and [§16](../principles.md) holds (the pass relays values [telemetry](../spec/systems/guardrails/telemetry.md)/[boot](../spec/systems/lifecycle/boot.md) own; audits owns no detection of the cache's content). The change adds **no field, no capability, no online behavior** — it pins a deferred build-spec committer, consistent with the honest bounds [D-198](0198-authorize-correcting-100-where-we-are-is-assembled-read-only.md)/[D-199](0199-resolve-the-d-198-standing-situation-correction-landed-text.md) set, and does not re-open them (build-orchestration still owns nothing about the cursor; boot still derives live; state stays the non-authoritative offline cache).

## What we ruled out

**Assign the audits *system* / read-only persona to refresh-and-commit** (rejected — the persona is read-only; the committer is the **workflow**; "audits refreshes" recreates [D-198](0198-authorize-correcting-100-where-we-are-is-assembled-read-only.md)'s relay-dressed-as-ownership category error). **A new standalone scheduled cron-commit actor** (rejected — the engine's first autonomous time-driven commit actor; a precedent break against riding existing committed passes). **The commit-boundary hook the [knowledge](../spec/systems/cognitive/knowledge.md) graph uses** (rejected — a per-commit GitHub network call adds latency to every commit; and lacking a drift gate, the "lands unstaged, captured by a following commit" mechanism has **no forcing function**, so the cache might never actually be committed). **Close-time refresh** (rejected — reopens the [D-038](0038-session-lifecycle-re-founded-on-native-substrates.md) bespoke-close-commit wound; [close](../spec/systems/lifecycle/close.md) commits nothing to the protected branch; per-session cadence is over-frequent for a degradation cache and couples freshness to session volume). **Boot persists what it derives** (rejected — [boot](../spec/systems/lifecycle/boot.md)'s read-only law, [D-199](0199-resolve-the-d-198-standing-situation-correction-landed-text.md): orientation never regenerates committed state). **Telemetry commits the cache** (rejected — already rejected by [D-199](0199-resolve-the-d-198-standing-situation-correction-landed-text.md); telemetry's "exactly one write" is issues-only). **Split the two cache fields across different mechanisms** (rejected — breaks [state](../spec/systems/cognitive/state.md)'s locked sibling invariant). **Fold the cache into the digest's fingerprint gate** (rejected — the cache has no committed referent to fingerprint against; it is schema-gated as a separate file riding the same PR). **Edit `state.json`'s committer into a locked doc as anything other than the deferred build-spec leaf it is** (rejected — the wiring stays a build-spec leaf; only the *owner* is pinned here).

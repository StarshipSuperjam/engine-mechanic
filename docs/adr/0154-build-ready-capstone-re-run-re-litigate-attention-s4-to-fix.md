## Why

The capstone's whole-corpus re-run is the last build-readiness gate, and its sole job is the one defect class a per-doc audit cannot see — two locked docs that disagree only when held together. It earned its keep: it surfaced S4, a live AF-1-class contradiction D-151 believed it had fully cleared. Even though the correct owner is recoverable (boot + build-orchestration agree, so a builder lands right via two of three docs), a live contradiction between two locked cognitive/lifecycle foundations should not ship into construction, where a builder reading attention would be told the plan-gate consent is boot's while boot disowns it. The fix lands on `attention` because it is the sole divergent doc — adapting divergent text to the settled cross-doc truth, never re-opening the gate's owner (the lock-discipline default). Critically, the orchestrator's **ground-truth re-adjudication — kept in the main session per the dry-run §4 HARD discipline — overturned the cold killers in BOTH directions**: it confirmed S4 (the killer over-refuted) and downgraded S3 (the killer over-confirmed as "survives"), exactly the over-tagging/over-refuting smell the instrument warns the orchestrator alone can catch. S3 is folded into the same one-doc re-litigation (a clarity nit in the same doc) to clear `attention` to clean in a single pass, per the operator's clean-before-the-line stance.

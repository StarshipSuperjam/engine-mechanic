# Authorize the first-run LICENSE-clear re-litigation: reconcile the traveled template LICENSE at greenfield instantiation (engine-template #147)

*Decided 2026-06-19 in the design workspace.*

## The decision

Authorize a re-litigation (litigation alarm) on explicit operator approval to make first-run instantiation **clear** the traveled template `LICENSE` and disclose it in plain language — touching locked [repository-topology](../spec/systems/infrastructure/repository-topology.md) (law 2) and [provisioning](../spec/systems/infrastructure/provisioning.md) (definition-of-record); the non-locked [risks](../reference/risks.md) ([R29](../reference/risks.md)), [scenarios/first-run](../architecture.md#first-run-provisioning), and [engine-architecture](../architecture.md). The operator chose **clear + disclose** over a neutral placeholder or a setup prompt. Provisioning is the definition-of-record; law 2 anchors the ownership and references it.

  **The litigation alarm.** engine-template ships a stock MIT `LICENSE` (`Copyright (c) 2026 StarshipSuperjam`, the template author — ground-truthed against `origin/main`) so the public template repo is legally usable. "Use this template" copies every committed file, so that LICENSE **travels into every generated repo and governs the adopter's own product** until replaced by hand — a legal-correctness defect (engine-template #147). The locked canon never covered it: [repository-topology](../spec/systems/infrastructure/repository-topology.md) law 2 names the engine-reconciled product-owned root set as exactly the root `README.md` + `SECURITY.md`, and [provisioning](../spec/systems/infrastructure/provisioning.md)'s apply phase seeds README + SECURITY.md + conduct, but neither names the LICENSE. #147's travel-safety *comment* was litigated separately ([D-219](0219-authorize-the-first-run-travel-safety-re-litigation-a-retire.md)/[D-220](0220-resolve-the-d-219-first-run-travel-safety-re-litigation-land.md)); #147's own LICENSE ask was never litigated, so #147 is blocked on this re-lock.

  **The decision — clear + disclose, the operator's choice among #147's three options.** A four-lens cold plan-audit (adversarial · technical-feasibility · non-engineer-operator · architect) ran against the proposed plan; it found **no fatal flaw in the choice** but **two blocking mechanism defects and a missing required carrier**, all folded into the authorized design:
  - **The behavior (provisioning, definition-of-record).** At **greenfield** first-run, apply **clears** (deletes) the root `LICENSE` **iff it positively matches the engine's own shipped template-license seed**, seeding **no replacement** (a license is a legal instrument the engine must not choose for the adopter; the generated repo is left with no `LICENSE`, GitHub's documented default-copyright state). On **brownfield** the engine overlay places only `.engine/` + keyed entries ([topology](../spec/systems/infrastructure/repository-topology.md) law 1), so a root LICENSE never lands — safe **by construction** *and* recognizer-gated (a product's own LICENSE never matches), the two guarantees not conflated. On **re-run/overlay** the slot no longer holds the engine seed → no-op; the engine never re-touches the root LICENSE after instantiation.
  - **The recognizer — specified, not borrowed (blocking fold).** The plan claimed "the exact predicate the README replace uses"; the audit refuted it. The README recognizer keys on an invisible leading HTML-comment marker (`<!-- engine-template:landing-front -->`) a `LICENSE` **cannot carry** (it must stay stock text for SPDX / GitHub license detection), and a body-only match would false-positive on an adopter who independently chose MIT and **delete their LICENSE**. The clear predicate is therefore a **conjunction**: the body matches the engine's shipped LICENSE seed **and** the copyright-holder line still names the **template author** (not the operator identity greenfield apply has already derived) — decidable, run **before** any identity-token substitution touches the LICENSE; **preserve on any doubt** (fails toward keeping). This recognizer **differs** from the README marker; the design names the discipline (positive-match-or-preserve), the concrete marker/content-match is a provisioning build-spec leaf.
  - **The disclosure — factual, never legal advice (blocking fold).** The plan's draft ("no license yet = all rights reserved (private by default); I can help pick a common one") gives **legal advice** with no [§17](../principles.md) non-AI correlate — "all rights reserved" is a legal conclusion (and wrong for a *public* repo, which GitHub's ToS leaves viewable/forkable), and offering to choose a license is counsel the engine (not a lawyer) must not give. The disclosure **law**: the engine **never silently clears a traveled root file**; the first-run note **names the removal and its cause** (the template author's license traveled in and would have governed *your* product, so it was removed; no replacement was added because the license is the operator's choice), **leads with the private-by-default reassurance** (a brand-new project with no license is the normal, safe starting state — your code is yours until you choose to share it), **routes the judgment out** (GitHub's `choosealicense.com` guide + "I can explain what a license file is and help you add one, but I can't tell you which terms are right for you" + a human for terms that matter), and **pre-empts the "No license" UI label**. The same visible-file-disclosure / non-weakening posture as the README and SECURITY seeds (**not** [§15](../principles.md) — a LICENSE is not a guardrail). The copy is a build-leaf to this law.
  - **Law 2 reframe — reconcile, not two verbs (architect fold).** Law 2 rises from "the engine **seeds** a narrow named set {README, SECURITY}" to "the engine **reconciles** a narrow named set of product-owned root files once at instantiation" — README/SECURITY **seeded**, the LICENSE **cleared** (the template's own, no replacement) — a *reconcile, not a claim* (clearing the engine's own traveled artifact is no more a claim than seeding is; law 1's "claims no other root path" holds). The clean single-predicate enumeration scales additively; law 2 **references** provisioning's recognizer + disclosure, never re-specifies them (the [D-218](0218-resolve-the-d-217-derived-committed-artifact-reconcile-re-li.md) byte-consistency discipline).
  - **Altitude — law 2, no new law or principle.** The README precedent ([D-213](0213-authorize-the-human-facing-front-door-re-litigation-the-root.md)/[D-214](0214-resolve-the-d-213-front-door-re-litigation-landed-text-cold.md)) is an exact altitude match; minting a new "distribution-artifact" law or a numbered principle is the structure-for-zero-gain anti-choice [D-213](0213-authorize-the-human-facing-front-door-re-litigation-the-root.md) already rejected.

  **Scope. Re-lock set — 2** (both currently locked → re-locked, none added): [repository-topology](../spec/systems/infrastructure/repository-topology.md), [provisioning](../spec/systems/infrastructure/provisioning.md). **Carriers (non-locked, authored this pass):** [risks](../reference/risks.md) ([R29](../reference/risks.md) — the LICENSE-leak, R26's *legal* sibling: reconciled as one model with two instances, shared recognizer/disclosure/brownfield-safe spine; names the two residuals below), [scenarios/first-run](../architecture.md#first-run-provisioning) (the apply-phase walkthrough adds the LICENSE-clear note, paralleling its README-replace/SECURITY-seed enumeration — the matrix's "reconcile affected scenarios/" trigger, the [D-213](0213-authorize-the-human-facing-front-door-re-litigation-the-root.md) precedent), [engine-architecture](../architecture.md) (the "one committed file that must not *stay* as shipped is the root README" callout becomes two — README *and* LICENSE). **Verify-no-edit (confirm at the landed-text audit):** [glossary](../reference/glossary.md) (**dropped from the plan's scope** — the LICENSE-clear is a one-off deletion with no dual-life concept or downstream referrers, unlike the README's earned "landing front" term; promoting a term would be R6 over-touch — verify-no-edit with this rationale), [modules/core](../spec/modules/core.md) (LICENSE is not a `FOUNDATION_INFRA`/`provides` artifact), [control-plane](../spec/systems/infrastructure/control-plane.md) (product territory), [ontology](../spec/systems/grammar/ontology.md) (a platform root file is not a surface — topology's "infrastructure artifacts are not surfaces"), [validation](../spec/systems/guardrails/validation.md)/[validators-core](../spec/modules/validators-core.md) (no check — the recognizer is a build-spec leaf, the sequencing gate a build-owe). **Build-owes (engine-template, downstream — not authored here):** (1) realize the clear in the instantiator apply phase (`_apply_substrates`, alongside the README/SECURITY seeds) with the **conjunction recognizer** (content-match ∧ template-author copyright-line — **not** the README's HTML marker, which breaks SPDX detection), run **before** identity substitution, preserve-on-doubt; (2) the template keeps shipping its stock MIT LICENSE (the recognizer keys off its content + holder line); (3) the **factual-not-advisory disclosure copy** (build-leaf to the message law above); (4) the **sequencing gate** ([R29](../reference/risks.md)-a) — the clear ships with/before any LICENSE content, so no window leaves a generated repo carrying the foreign copyright; (5) regenerate `graph.json` last, full suite + `validate --suite CI` green, one `guardrail-ack`. **Residuals (named, build-or-log is the operator's call):** (a) a maintainer who *genuinely intends* adopters to inherit license terms ships them as an **explicit authored template choice** (the seed-then-own pattern), never the silent default — the clear protects the unknowing adopter, the override serves the deliberate maintainer; (b) an adopter **generated before this ships** (or a slip-through) still carries the foreign-copyright LICENSE — the clear fires only at first run, so the indicated remedy is a **standing boot-time detect-and-offer** ("a root LICENSE names a copyright holder that isn't you" → offer to clear, on consent — the [R20](../reference/risks.md) stranded-checkout pattern), named in [R29](../reference/risks.md). The re-locks land under the **Resolve** entry ([D-222](0222-resolve-the-d-221-first-run-license-clear-re-litigation-land.md)) after the mandatory landed-text cold audit.

## Why

The litigation-alarm protocol authorizes a locked-doc change on explicit operator approval, and the gap is real and live: the template's own copyright travels into and governs every adopter's product, and the locked canon never named the LICENSE among the reconciled root files. Clear-without-seed is the only option that fixes the defect **without the engine choosing a license for a non-engineer** (a legal act it has no standing to perform); a placeholder is a foreign artifact squatting in product territory, a prompt asks a non-engineer to make a licensing call. The plan-audit's folds — the README recognizer does not transfer (a LICENSE cannot carry the marker and a body-match would delete an adopter's own license), the disclosure must inform without advising, law 2 must reconcile not special-case, first-run must stay a truthful walkthrough, the glossary term is over-touch — are folded into this authorized wording before any edit, which is what makes this a litigated change rather than a session reflex.

## What we ruled out

**Replace the LICENSE with a neutral placeholder** (rejected — any seeded license file is the engine choosing the adopter's legal terms; even a TODO placeholder is a foreign artifact in product territory a tool could misread). **Prompt the adopter to pick a license at setup** (rejected — asks a non-engineer to make a licensing judgment they cannot, and expands the interactive gather phase). **Borrow the README recognizer ("the exact predicate")** (rejected — a LICENSE cannot carry the invisible marker without breaking SPDX detection, and a body-only match deletes an adopter's own MIT license; the predicate is a content ∧ author-line conjunction run before identity substitution). **State "all rights reserved / private by default" as fact and offer to pick a license** (rejected — a legal conclusion with no [§17](../principles.md) non-AI correlate, wrong for public repos, and advice the engine must not give; the disclosure informs and signposts, never counsels). **File the LICENSE-clear under law 2's "seeds once"** (rejected — a clear is not a seed; law 2 rises to "reconciles," seed/clear per-file). **Mint a new distribution-artifact law or §20 principle** (rejected — the [D-213](0213-authorize-the-human-facing-front-door-re-litigation-the-root.md) README precedent fits law 2 exactly; new structure for zero gain). **Add a glossary "Root LICENSE" term** (rejected — a one-off deletion with no dual-life concept; R6 over-touch). **Omit scenarios/first-run** (rejected — it enumerates the apply-phase reconciliations and would be untruthful without the LICENSE-clear, the [D-213](0213-authorize-the-human-facing-front-door-re-litigation-the-root.md) carrier precedent).

# Lock the `state` system (Wave-2 head): the committed cursor, reconciled to native substrates

*Decided 2026-05-25 in the design workspace.*

## The decision

Ratify and lock [state](../spec/systems/cognitive/state.md) to its end-state as the cognitive substrate's **"where am I?" cursor** — the first Wave-2 lock and the head of the [D-052](0052-foundational-law-layer-closed-the-implementation-lock-order.md) cognitive runway (unblocked now that [D-058](0058-discharge-the-wave-0-gate-q10-substrate-content-world-taggin.md) discharged the Wave-0 gate). State is **one schema-validated, committed, git-native machine-state file** — a *permitted committed pointer* file ([repository-topology](../spec/systems/infrastructure/repository-topology.md) law 5, configuration-not-data), laid in its own `.engine/` subtree per topology's Tier-2 placement law — holding **pointers and counts only**: the project's standing-situation pointers, and a **debt count + as-of marker + pointer** into [telemetry](../spec/systems/guardrails/telemetry.md)'s engine-labeled-Issue register (a derived convenience, never authoritative; canonical source is the open Issues per [D-040](0040-telemetry-designed-end-state-native-signal-of-record-tracked.md)). The lock reconciles the doc to decisions made after it was authored and **removes two pre-[D-029](0029-cognitive-substrate-is-one-workflow-a-2-store-1-register-1-c.md)/[D-038](0038-session-lifecycle-re-founded-on-native-substrates.md) residues**: the committed **candidate work list** (superseded — "what's next" is the native git/GitHub record: branches/PRs = in-flight, Issues = deferrals/backlog, Milestones = plan, *ordered* by [attention](../spec/systems/cognitive/attention.md)) and the **bounded narrative companion** (superseded — current work is the open draft PR body, recent work is merged PR bodies + memory). State persists **no session stance** (every session boots Explore; stance is session-runtime per [modes](../spec/systems/lifecycle/modes.md)), **no depth** ([memory](../spec/systems/cognitive/memory.md)/[knowledge](../spec/systems/cognitive/knowledge.md)), and **not the debt register itself** (telemetry owns it). Five laws are fixed: **(1)** the malformed file **fails loud — refused, never fed to the model as a misleading cursor** (the schemas/validation halt-on-malformed posture, strengthened), while the *session* does not crash — [boot](../spec/systems/lifecycle/boot.md) surfaces the refusal via injected `additionalContext` + a telemetry finding (never a `SessionStart` exit-code halt) and falls through to the hook-independent root `CLAUDE.md` floor (fail-loud within fail-open); **(2)** honest **degradation limits** — the floor answers standing-situation + last-known debt count + local git offline, while deferrals/plan (Issues/Milestones) degrade with GitHub on any read failure (outage or expired auth), loud-and-consented; **(3)** double-fault legibility (corruption + `SessionStart` also failing) is the hook-independent floor's job, deferred to boot's root-`CLAUDE.md` expectation-setter, not loaded onto state; **(4)** the standing-situation pointer **advances on committed acts**, so an Explore-only stretch (which commits nothing) leaves it correctly intact; **(5)** the exact field set / JSON Schema is the **build-spec leaf** ([D-052](0052-foundational-law-layer-closed-the-implementation-lock-order.md), laws-not-leaves). The seams to its still-`designed` neighbours (attention orders; telemetry owns+refreshes debt; memory/knowledge hold depth; boot reads+surfaces; modes decides stance) are **pure deferrals**, so no neighbour's later lock can force a state change. Reconciliations to non-locked docs: [attention](../spec/systems/cognitive/attention.md) (candidate work is native git/GitHub, attention orders), [glossary](../reference/glossary.md) (State entry → pointers-and-counts-only), and the [github-projects-sync](../spec/modules/github-projects-sync.md) stub (drop the dissolved `eager-claim`/`sessions` framing). **No locked doc is edited** — the schemas/validation "halt-on-malformed posture" citations are strengthened, not changed, so **no re-litigation alarm**.

## Why

State is the upstream-anchored head of the cognitive substrate — read first by every session, depending only on locked docs (topology law 5, schemas, ontology) plus pure deferrals to its designed neighbours — so it is the correct first Wave-2 lock under the lock discipline. Most of the lock is *reconciliation, not invention*: [D-029](0029-cognitive-substrate-is-one-workflow-a-2-store-1-register-1-c.md) already scoped state to "one cursor, tiny pointers incl. a debt count," and [D-038](0038-session-lifecycle-re-founded-on-native-substrates.md)/[D-040](0040-telemetry-designed-end-state-native-signal-of-record-tracked.md) already moved work, narrative, and debt to native substrates; the candidate work list and narrative companion were residues those decisions had superseded in spirit but not yet on the page. Removing them makes state genuinely tiny (the first thing read stays cheap), keeps every growing thing with its owner, and serves the cold-start, degradability, and trust attributes. The four-lens cold-session design audit ([D-018](0018-cold-session-design-audit-required-before-any-lock.md): adversarial / technical-feasibility / non-engineer-operator / architect, no shared context) ran against the design before this entry; it confirmed the removals correct, the lock-discipline sound, and (architect grepped all 16 locked docs) **no re-lock needed**, and its blocking/serious findings were resolved into the laws before the lock: **(adversarial, blocking)** the malformed-state reframe must keep the locked schemas/validation citation truthful → resolved by stating the *file* fails loud (refused), only the *process* degrades, strengthening not changing those citations; **(adversarial + operator, serious)** the offline "what's next" / stale-count gaps → resolved by the honest-degradation-limits law and an as-of debt-count marker rendered with provenance; **(operator, blocking)** the corruption + `SessionStart`-failure double fault could silently strand a non-engineer on the thin floor → resolved by deferring the standing root-`CLAUDE.md` expectation-setter to boot; **(technical-feasibility, serious)** `SessionStart` has no block semantics → resolved by specifying injection + finding, never an exit-code halt; **(architect, blocking + serious)** the unlocked [glossary](../reference/glossary.md) State entry and the [github-projects-sync](../spec/modules/github-projects-sync.md) stub were missing propagation targets → both added and reconciled. Technical-feasibility verified every platform fact (SessionStart context injection + fail-open; root `CLAUDE.md` hook-independent auto-load; JSON Schema 2020-12 on a committed pointer file; gh/MCP enumeration of branches/PRs/Issues/Milestones with committed-count fallback; "Use this template" copies committed files while gitignored data does not).

## What we ruled out

Keep the committed candidate work list (rejected — it would drift from the native git/GitHub record [D-038](0038-session-lifecycle-re-founded-on-native-substrates.md) made canonical; a derivative must never become a second source of truth, [principle §2](../principles.md)). Keep the bounded narrative companion (rejected — [D-038](0038-session-lifecycle-re-founded-on-native-substrates.md) routes current-work narrative to the draft PR body and past-work to merged PRs + memory; a committed prose log duplicates them and rots). Persist session stance in state (rejected — every session boots Explore and never self-flips, [D-038](0038-session-lifecycle-re-founded-on-native-substrates.md)/[modes](../spec/systems/lifecycle/modes.md); a persisted stance could resurrect a crashed Build session into write-enabled mode unattended). Make the committed debt **count** authoritative (rejected — the canonical register is telemetry's view over open engine-labeled Issues, [D-040](0040-telemetry-designed-end-state-native-signal-of-record-tracked.md); the count is a derived convenience for the degraded read, carried with an as-of marker so it is never read as gospel). Drop the debt count entirely and always query GitHub (rejected — it is precisely the value a GitHub-outage / offline boot needs so the operator is not stranded, [telemetry](../spec/systems/guardrails/telemetry.md)). Hard-halt boot on a malformed state file (rejected — fights the hooks fail-open law and strands a non-engineer; refuse-the-file + surface + fall to floor is fail-loud within fail-open). Freeze the exact field set in the lock (rejected — laws-not-leaves, [D-052](0052-foundational-law-layer-closed-the-implementation-lock-order.md); the JSON Schema is the build-spec leaf, as every locked surface deferred its concrete schema). Edit the locked schemas/validation docs to match the sharpened wording (rejected — unnecessary; the "file fails loud" posture they cite is preserved and strengthened, so no re-litigation alarm is warranted).

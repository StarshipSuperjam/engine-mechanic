# Foundational law layer closed; the implementation lock-order runway

*Decided 2026-05-25 in the design workspace.*

## The decision

Declare the corpus's **cross-cutting law layer closed** and adopt the system-design **lock-order runway** for the implementation phase. **(1) Law-surface coverage** is now complete across three homes: the **11 locked systems** (the grammar spine + foundation contracts — [ontology](../spec/systems/grammar/ontology.md), [module-system](../spec/systems/grammar/module-system.md), [templates](../spec/systems/guardrails/templates.md), [validation](../spec/systems/guardrails/validation.md), [check](../spec/systems/surfaces/check.md), [contracts](../spec/systems/surfaces/contracts.md), [policies](../spec/systems/surfaces/policies.md), [schemas](../spec/systems/surfaces/schemas.md), [control-plane](../spec/systems/infrastructure/control-plane.md), [hooks](../spec/systems/infrastructure/hooks.md), [repository-topology](../spec/systems/infrastructure/repository-topology.md)); the **15 cross-cutting [principles](../principles.md) §1–§15** (§15 added by [D-051](0051-guardrail-integrity-the-builder-cannot-silently-weaken-its-o.md)); and the **[D-042](0042-procedural-content-grounding-surface-cluster-designed-the-bo.md)** procedural/grounding boundary laws atop the grammar. No other cross-cutting law remains unstated: every designed system's open thread is *leaf* (concrete schema / policy / field-set, owned by its own build session), every [deviation](../reference/prototype-deviations.md) is DECIDED or leaf-OPEN, and the one residual law-*risk* — [Q10](../reference/open-questions.md) — is logged as the gate that must be cleared before the first cognitive lock. **(2) The lock-order runway** (the sequence the per-system fleshing-out/lock sessions follow; upstream-anchored first, never locking atop a churning `designed` neighbour — the [lock discipline]):
  - **Wave 0 — gate:** clear [Q10](../reference/open-questions.md) (module grammar can express the substrate's world-tagging, else litigate) before any cognitive lock.
  - **Wave 1 — surfaces** (grammar-governed, unblock downstream): [tools](../spec/systems/surfaces/tools.md), [operations](../spec/systems/surfaces/operations.md), commands, [docs](../spec/systems/surfaces/docs.md), [skills](../spec/systems/surfaces/skills.md), [agents](../spec/systems/surfaces/agents.md) (the last with its `output-contract` schema per [D-046](0046-harness-comparative-mining-a-guardrail-integrity-gap-a-contr.md)).
  - **Wave 2 — cognitive substrate** ([D-029](0029-cognitive-substrate-is-one-workflow-a-2-store-1-register-1-c.md) one workflow, after Wave 0): [state](../spec/systems/cognitive/state.md) → {[knowledge](../spec/systems/cognitive/knowledge.md), [memory](../spec/systems/cognitive/memory.md)} → [attention](../spec/systems/cognitive/attention.md) → [boot](../spec/systems/lifecycle/boot.md); [interfaces](../spec/systems/surfaces/interfaces.md) locks here (its v1 members `search` + knowledge-retrieval bind it to the cognitive retrieval leaf).
  - **Wave 3 — lifecycle:** [modes](../spec/systems/lifecycle/modes.md) (after boot grounding), [close](../spec/systems/lifecycle/close.md) (after memory capture), [build-orchestration](../spec/systems/lifecycle/build-orchestration.md) (after modes + agents).
  - **Wave 4 — guardrails judgment:** [telemetry](../spec/systems/guardrails/telemetry.md) (after attention-surfacing + boot + build-orchestration, per [D-040](0040-telemetry-designed-end-state-native-signal-of-record-tracked.md)), then [audits](../spec/systems/guardrails/audits.md) (after telemetry + agents, per [D-041](0041-audits-designed-state-a-purpose-built-adversarial-self-revie.md)).
  - **Wave 5 — infrastructure last:** [provisioning](../spec/systems/infrastructure/provisioning.md) (after memory's backup path + modes + boot, per [D-048](0048-provisioning-delivery-designed-end-state-brownfield-capable.md)).
  The runway is revisable: a superseding entry reorders a wave as edges firm. Intra-wave order is soft (those systems are genuinely parallel); inter-wave order and Wave 0 are hard.

## Why

The law precedes the leaf ([D-003](0003-specify-the-full-end-state-before-the-first-build-pr.md)): once the cross-cutting laws are settled, each system can be fleshed out and locked without its features forcing a foundation refactor. Declaring closure is a statement about the *law* surface specifically — D-003 separates it from the implementation that follows, so closure does not wait on the leaves. The runway encodes the established cross-system dependencies ([D-029](0029-cognitive-substrate-is-one-workflow-a-2-store-1-register-1-c.md) cognitive-as-one-workflow, [D-040](0040-telemetry-designed-end-state-native-signal-of-record-tracked.md)/[D-041](0041-audits-designed-state-a-purpose-built-adversarial-self-revie.md) the telemetry→audits judgment ladder, [D-048](0048-provisioning-delivery-designed-end-state-brownfield-capable.md) provisioning-late, [D-042](0042-procedural-content-grounding-surface-cluster-designed-the-bo.md) surfaces-on-grammar) plus the [Q10](../reference/open-questions.md) gate, so no session locks atop an unsettled upstream — the failure the lock discipline exists to prevent. This is a planning-workspace process milestone (like [D-004](0004-establish-the-engine-planning-workspace-with-a-fixed-documen.md)/[D-018](0018-cold-session-design-audit-required-before-any-lock.md)), not an Engine-design decision.

## What we ruled out

Lock systems in arbitrary or fully-parallel order (rejected — the lock discipline forbids locking atop a churning `designed` neighbour; the waves encode the real dependencies). Fold the runway into the WBS (rejected — a different axis: the WBS is the module *build* order and is blocked on the [Q1](../reference/open-questions.md) membership verdicts, whereas this is the system-*design* lock order and is not). A strict linear 1-of-18 order (rejected — over-precise; several intra-wave edges are genuinely parallel, and false precision invites needless re-litigation). Give the runway its own top-level doc now (rejected — new-doc ceremony for a sequence that the decision-log records cleanly and that a superseding entry can revise; it is consumed as systems lock). Defer declaring closure until every leaf is designed (rejected — conflates the law layer with the implementation layer D-003 separates).

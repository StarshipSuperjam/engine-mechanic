# Lock the `memory` system (Wave-2): the episodic ledger store; Q3 backup-path resolved

*Decided 2026-05-25 in the design workspace.*

## The decision

Ratify and lock [memory](../spec/systems/cognitive/memory.md) — the cognitive substrate's "how did I get here?" experiential store — to its end-state, and **resolve Q3/Risk [R2](../reference/risks.md)** (the automatic backup path), the one open design decision that blocked the lock. The settled design (firmed to final voice): **ledger-canonical** — an append-only **NDJSON ledger** is the one source of truth, the SQLite/FTS5 index a derived rebuildable accelerator (degrading to a plain ledger scan if FTS5 is absent); **observe-don't-predict capture** (cheap, generous, episodic; AI judgment types/tags, never gatekeeps; importance derived from usage/frecency); **ambient append at every `Stop` + deferred consolidation at `PreCompact`/graceful close + an abandoned-session sweep keyed on the Claude Code session-id** (capture never depends on a graceful close); **two-layer typing** (closed Engine-shipped role vocabulary + open project tags); **lexical floor + semantic-recall module behind the `search` [interface](../spec/systems/surfaces/interfaces.md)**; the **read-time memory↔knowledge join** on entity-id tags (no persisted reverse edges, [D-008](0008-memory-and-knowledge-are-distinct-substrates.md)/[D-030](0030-memory-ledger-canonical-observe-don-t-predict-capture-lexica.md)); the **built-in-auto-memory boundary** (the Engine substrate is authoritative for project recall; built-in auto-memory is the contributor's personal notebook, never the project record); **active forgetting** (consolidate / demote / hard-delete-only-on-evidence) that is **operator-visible and reversible, surfaced at the next [boot](../spec/systems/lifecycle/boot.md) with an undo-by-plain-language-item handle**; **ships empty**, gitignored, **institutional-recall scope** (no per-record world tag; Engine self-monitoring stays the separate [D-039](0039-reports-self-improvement-scope-engine-only-self-monitoring-o.md) issue store, [D-058](0058-discharge-the-wave-0-gate-q10-substrate-content-world-taggin.md)). **Q3 backup law:** the Engine performs an **automatic, per-project-namespaced export** of the ledger (+ a snapshot manifest) to an **operator-configured off-repo destination**, **v1 default a private GitHub repo via the operator's `gh`**; the backup is a **copy** (canonical stays the local gitignored ledger; topology law 5's committed-pointer carve-out covers the destination pointer — **no topology edit**); **default one repo per project**, shared vault an **opt-in** whose namespacing is organizational-not-isolation; **privacy is posture** (create/verify-private + `repo`-scope probe + periodic privacy re-check; cannot prevent a later out-of-band flip, named honestly per [principle §7](../principles.md)); **restore = replace ledger + rebuild index** (via `migrations` on a schema change); **one mechanism, two consumers** — the same export/import is [provisioning](../spec/systems/infrastructure/provisioning.md)'s pre-migration snapshot/reversal ([D-048](0048-provisioning-delivery-designed-end-state-brownfield-capable.md)), with **memory the sole owner/definer of the mechanism + restore contract and provisioning a consumer that may not widen it**, so provisioning's later Wave-5 lock cannot force a memory change; and **operator-facing floors** asserted in the law (consent-before-create; a committed plain-language README in the backup repo; auto-offered restore on a fresh matching-namespace instance; degrade-and-disclose names consequence + one recovery action). The destination/UX, shared-vs-per-project selection, scope-grant interaction, cadence, and command wording **defer to provisioning's Q4 leaf**. **No locked doc is edited** (topology law 5 already pre-authorized the backup pointer; the capture-timing, read-time-join, and scent references in locked hooks/knowledge/skills/state stay truthful) — **no re-litigation alarm**. **Q11 stays open** (commit to no frontier engine; the plain-JSON/lexical floor ships behind the swappable interface). The concrete role-vocab schema, ranking, forgetting scores, and MCP roster are **build-spec leaves**; the [D-030](0030-memory-ledger-canonical-observe-don-t-predict-capture-lexica.md) role vocabulary is already closed.

## Why

Memory is the second Wave-2 store; it locks after knowledge because it carried the one open design decision (Q3). The backup mechanism is the smallest design that satisfies the [R2](../reference/risks.md) constraints — automatic (a non-engineer won't copy a gitignored file), trusted + no-path-knowledge (the operator's own GitHub, granted at bootstrap), no leak into the product/template (a separate off-repo private repo, not the gitignored ledger committed), and reused for [D-048](0048-provisioning-delivery-designed-end-state-brownfield-capable.md)'s migration reversal — and it lands inside topology law 5's existing committed-pointer carve-out, so it needs no locked-doc change. A four-lens cold-session design audit ([D-018](0018-cold-session-design-audit-required-before-any-lock.md): adversarial / technical-feasibility / non-engineer-operator / architect, no shared context) ran against the joint knowledge+memory design and returned **no blocking findings**; its serious findings were folded before this entry: **(adversarial + feasibility)** "must be private / refuse public" overclaimed a guarantee the platform does not give → reworded to honest posture (create/verify + periodic re-check; cannot prevent a later flip); **(adversarial)** a shared vault co-locates many projects' memory under one credential, the cross-project concern [D-007](0007-memory-data-is-local-and-gitignored-substrate-ships-empty.md) weighed → resolved by defaulting to per-project, making the vault opt-in, and stating namespacing is organizational-not-isolation; **(architect + adversarial)** locking memory while provisioning is `designed` risks a later provisioning lock forcing a change → resolved by asserting memory owns the mechanism + restore contract and provisioning only consumes; **(non-engineer-operator, five serious)** the law deferred the operator's moments-of-contact to Q4, where a developer-only affordance could satisfy a deferred adjective → resolved by asserting operator-facing **floors** in the law (consent-before-create, self-describing README, auto-offered restore, boot-surfaced reversible forgetting, consequence+recovery disclosure), leaving only UX wording to Q4; **(feasibility)** FTS5 may be absent → plain-ledger-scan degrade added. Technical-feasibility verified the platform facts (`gh repo create --private` + push + visibility read; `repo` scope incremental on the default operator login; `Stop`/`PreCompact`/`SessionStart` hooks and the session-id; FTS5/BM25 + rebuild-from-ledger; the MCP-over-gitignored-data model; restore-as-replace-and-rebuild).

## What we ruled out

Commit the ledger to the product repo / an orphan branch / a release asset (rejected — leaks experiential memory into the product tree, travels with clone/fork, and violates [D-007](0007-memory-data-is-local-and-gitignored-substrate-ships-empty.md)/topology law 5; the backup must be a separate off-repo private store). An OS cloud-synced folder as the default (rejected — brittle per-OS path discovery, leans on the non-engineer knowing/picking a synced folder, not GitHub-native, invisible sync/quota failures). A shared cross-project vault as the default (rejected — co-locates memory under one credential against [D-007](0007-memory-data-is-local-and-gitignored-substrate-ships-empty.md)'s leakage concern; per-project is the safe default, shared is an informed opt-in). State "refuses a public backup store" as a hard guarantee (rejected — the platform gives no standing veto on a later flip; honest posture is create/verify + periodic re-check, [principle §7](../principles.md)). Defer the operator-facing guarantees wholesale to provisioning's Q4 UX (rejected — a deferred adjective can be satisfied by a developer-only affordance that strands a non-engineer; the floors are guarantees and live in the law, only their wording defers). Leave memory `designed` until provisioning locks (rejected — memory is upstream: it owns the backup mechanism provisioning consumes, so locking it now fixes the contract provisioning builds against, and the consume-not-widen assertion keeps provisioning's later lock from forcing a memory change). Adopt a frontier memory engine now (rejected — Q11 stays open; the lexical/ledger floor ships behind the swappable `search` interface). Edit topology for the backup pointer (rejected — law 5 already carves out a committed config/pointer "without re-litigation").

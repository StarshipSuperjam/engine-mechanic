# Enrich the derived knowledge-graph schema (a build-spec leaf) with declared-structural depth, under a durable four-gate rule

*Decided 2026-06-16 in the design workspace.*

## The decision

The built v1 [knowledge](../spec/systems/cognitive/knowledge.md) graph harvests far less than its source surfaces *declare*: `knowledge.v1.json` carries only `{id, type, name(=path), slug, source, owner, predicates}` with a closed four-edge set (`provided_by, governed_by, targets, depends_on`) and no `status`, `tier`, or `supersedes`. The entity/edge schema is an explicit **build-spec leaf** (the knowledge README fixes the laws; [D-042](0042-procedural-content-grounding-surface-cluster-designed-the-bo.md) settles only the surface *set*), so the generator is to **harvest more of what surfaces already declare** — a richer derived map for cold-session comprehension — governed by a **durable four-gate rule**, with the concrete v1 field/edge list its *illustrative application* (not a closed list — a future declared field is admitted by the gates, not by appearing here, per the [D-116](0116-q27-3-re-litigation-the-knowledge-retrieval-interface-operat.md) "selectors are illustrative" lesson).
  - **The four gates (durable):** **(1) Declared, not interpreted** — sourced from a frontmatter/manifest field or a deterministic structural parse, never from prose *meaning* ([§3](../principles.md), [D-011](0011-knowledge-graph-state-is-derived-not-hand-authored.md)). **(2) Structure, not belief** — entity/relationship/attribute/lifecycle-state only; never rationale, significance, summary/description, judgment, or importance ([D-008](0008-memory-and-knowledge-are-distinct-substrates.md) wall). **(3) Forward-only, canon-clean** — no reverse edges (reverse = `neighbors(direction:in)` at query time from the single stored forward edge); **no persisted reference — edge OR attribute — targets a canon eADR** ([D-169](0169-add-the-foundational-eadr-canon-the-engine-ships-its-own-why.md) / [contracts](../spec/systems/surfaces/contracts.md)); no edge into memory (the link stays consumer-composed, [D-116](0116-q27-3-re-litigation-the-knowledge-retrieval-interface-operat.md)). **(4) Re-derivable + swap-safe** — deterministic from committed source on the fingerprint-gated regen (byte-identical on unchanged source); representation-agnostic so a future dense-graph engine ([Q11](../reference/open-questions.md)) re-derives it unchanged.
  - **The v1 set (illustrative).** *Node attributes:* `status` (declared lifecycle enum — contracts `proposed|accepted|superseded`, modules `required|default-on|optional|experimental|retired`, else `active`; the **state token only**, never the *why* of a supersession); `tier` **for checks only** (`hard|soft` — policy tier is a prose `##` section, not derivable, excluded); discriminators (check `kind`+`suites`; agent `role`+`lens`+`model-tier`; skill `invocation`; interface `operations`+`fallback` handle; module `version`+`status`); and the narrowed identity `title` (ruling below). *Forward edge:* `supersedes` (contract→contract), **scoped to non-canon deployment-stream contracts** so no edge targets a canon eADR.
  - **The PULL-path spine (the budget-safety proof).** New depth is **pulled on demand** via the locked op-set `get-entity / find / neighbors / relate` ([D-116](0116-q27-3-re-litigation-the-knowledge-retrieval-interface-operat.md)). New **edge types are budget-neutral unless the cold-start adjacency walk traverses them — and the invariant is they are not added to the walk's traversal set**; new **attributes** add only bounded per-entity bytes to the structural-neighbours pull (net-positive — they save file-opens — not literally zero). The cold-start walk's traversal edge-set is pinned to today's edges as a build-spec invariant homed in the [attention](../spec/systems/cognitive/attention.md) policy (the surface that already owns budget allocation/trim order), so budget-neutrality is enforced, not hoped.
  - **The D-008 identity-`title` ruling (operator-authorized; narrowed by an execution re-check).** A human-legible identity label is admitted **only where the type's title CONVENTION is a constrained bare noun-phrase, verified against live instances** — *not* "all types except contract." A focused adversarial re-check (ground-truthed against the built `.engine/`) **falsified the first-pass line**: `operation` titles are directive/purpose compounds (*"Remove the engine — take it out cleanly and leave a working, engine-free project"*) = belief; `check`/`tool`/`schema`/`module`/`agent` declare **no** title (slug already carries identity); `contract` titles are decision-claims; `doc` titles are operator-prose headlines (low value). **Surviving three-type set: `policy.title`, `interface.title`, `skill.name`** — declared single-line bare names, harvested verbatim, identity field only (never `interface`/`skill` `description`), **no slug fallback**, with a noun-phrase shape-guard (reject em-dash purpose clauses / mid-string sentence punctuation / imperative-verb phrasing) against future drift. This is a logged *boundary interpretation* of the wall (nothing belief-bearing is admitted; the strings are the same token-kind as the slug the graph already holds) — the knowledge README text is preserved, **no re-lock**.
  - **Lock & propagation.** **No locked-doc edit, no litigation alarm, no re-lock** — the schema is a build-spec leaf and the set obeys every governing law ([D-008](0008-memory-and-knowledge-are-distinct-substrates.md), [§3](../principles.md)/[D-011](0011-knowledge-graph-state-is-derived-not-hand-authored.md), [D-116](0116-q27-3-re-litigation-the-knowledge-retrieval-interface-operat.md) op-set + no-reverse-edges + consumer-composed memory link, the [D-169](0169-add-the-foundational-eadr-canon-the-engine-ships-its-own-why.md) canon invariant). [risks.md](../reference/risks.md) **[R8](../reference/risks.md)** gains an affirming clause (the enrichment stays sparse / declared-only / forward-edge-only with no hub fan-out — it does **not** instantiate hub-explosion; mirrors the [D-169](0169-add-the-foundational-eadr-canon-the-engine-ships-its-own-why.md) eADR-canon move). [glossary](../reference/glossary.md) "Knowledge" entry reviewed — **no edit owed** (it sits at concept altitude — "what exists and how it relates, purely derived" already covers a richer harvest; the belief-wall is captured in the *CoALA* line; schema-granularity detail there would pin a build-spec leaf and risk rot). [engine-architecture](../architecture.md) reviewed — no edit owed (role+link level, unaffected). The knowledge README stays untouched (it already defers the schema to build-spec). **Build owes conformance** (downstream, in `engine-template`, not authored here): open the closed `predicates` set + add the attribute fields in `knowledge.v1.json`; the generator harvests the declared fields with byte-deterministic output; the fingerprint-coverage check covers the new fields; the [§12](../principles.md) vocabulary leak-guard extends to the new enum *values* (`hard`/`soft`/`posture`/`retired`/`experimental` never echoed verbatim to the operator); the AI treats graph `status` as as-of-last-regen and verifies a supersession against the live file before asserting it.
  - **Process.** A four-lens cold plan-audit (adversarial · technical-feasibility · non-engineer-operator · architect) reshaped the draft: it **dropped** `title`-broad, `established_by` (an attribute reachable via the locked `find(attribute)` op = a canon back-door), `implemented_by`-as-edge (its declared `fallback.handle` is an MCP server name, not a resolvable entity-id → kept as the `fallback` attribute), and `disables` (conduct is one entity per *file*, ids are per-*code* → no node to target); **deferred** `delegates_to` (a code-span path token, ordering/resolution unspecified → fingerprint-churn risk; agents not yet built); **scoped** `tier` to checks (policy tier is prose-only); and added the **R8** + budget + traversal-owner corrections. A focused adversarial re-check then narrowed the identity-`title`.

## Why

The AI's weakest point on a large system is grasping cross-surface relationships fast and reliably; the derived graph is the truest, cheapest channel for that, and it was under-harvesting declared structure. Enriching it is the kind of change the lock *anticipated* (the schema is a declared build-spec leaf), so it lands within the locked laws — provided each field is mechanically declared, structural (never belief), forward-only and canon-clean, and re-derivable. Routing the depth onto the pull path keeps orientation/scent budget flat. The gates are logged as the durable output so future enrichment is governed by them, not by copying this list.

## What we ruled out

**A large hand-authored feature index as the session's knowledge source** (rejected — [§3](../principles.md): hand-authored structural state rots silently; the derived graph stays the source of truth). **`title` for all non-contract types** (rejected — `operation`/`doc` titles and `skill`/`interface` `description` carry purpose/judgment = belief; falsified against live instances). **`established_by` provenance in the graph** (rejected — edge targets a canon eADR; attribute reachable via `find(attribute)` — both breach the [D-169](0169-add-the-foundational-eadr-canon-the-engine-ships-its-own-why.md) canon invariant; provenance stays in the policy's own frontmatter). **`implemented_by` as an interface→tool edge** (rejected — no resolvable target; kept as the `fallback` attribute). **`disables` edge** (rejected — entity-granularity mismatch; override stays consumer-composed). **`ratifies` / `implements_principle` (contract→principle)** (rejected — [contracts](../spec/systems/surfaces/contracts.md) pins "no forward `ratifies` edge"; principles are not entities; re-litigates a locked invariant). **Reverse edges** (rejected — redundant with `neighbors(direction:in)`). **Belief/semantic fields, prose `governs`/`cites`** (rejected — gates 2 and 1). **Edit/re-lock the knowledge README** (rejected — the schema is a declared build-spec leaf; the laws it fixes are unchanged). **Add the new edge types to the cold-start walk** (rejected — would consume orientation budget; the walk's traversal set stays pinned).

# Lock the `modes` system (Wave 3 head): three stances on two axes, an honest fallible Explore gate, session-scoped stance

*Decided 2026-05-26 in the design workspace.*

## The decision

Ratify and lock [modes](../spec/systems/lifecycle/modes.md) — the session's operating **stance** — to its end-state, the **head of Wave 3** on the [D-052](0052-foundational-law-layer-closed-the-implementation-lock-order.md) runway. Modes is **three stances on two mechanically-real axes** (permission posture × attendance): **Explore** (default, interactive, writes gated off), **Build** (interactive, write), **Routine** (unattended, scope-locked); the fourth cell (unattended-read) is **intentionally empty** — scheduled read-only work runs as GitHub Actions cron, not a session stance. Locking modes first is correct: every reference to it across the **22 locked docs is a deferral *to* modes** (grep-verified — [state](../spec/systems/cognitive/state.md) "modes decides stance"; [boot](../spec/systems/lifecycle/boot.md) "the stance vocabulary and the write-gate are modes'"; [hooks](../spec/systems/infrastructure/hooks.md) "the explore write-gate registers with modes"; [skills](../spec/systems/surfaces/skills.md) "the concrete mode-entry verbs are modes' leaf"; [attention](../spec/systems/cognitive/attention.md) "modes stance gating already owns" claim/scope/mode enforcement; [policies](../spec/systems/surfaces/policies.md) the routine-escalation arm), so the lock edits **no locked doc** — the [D-063](0063-lock-the-boot-orientation-system-wave-2-terminal-the-integra.md)/[D-064](0064-lock-the-interfaces-surface-final-wave-2-lock-single-active.md) honor-the-deferrals pattern — and its `designed` Wave-3 neighbors ([close](../spec/systems/lifecycle/close.md), [build-orchestration](../spec/systems/lifecycle/build-orchestration.md)) depend on modes, not the reverse. The fixed laws: **(1) stance is session-scoped and never persists** — an ephemeral signal keyed to the live session in non-repo storage, never committed, resolving to Explore in every ambiguous case, so every session boots Explore and a crashed Build session cannot resurrect as Build (the mechanical realization of locked [state](../spec/systems/cognitive/state.md)'s "never persisted", honored not merely asserted); **(2) the Explore write-gate denies an enumerated *building* set and allows everything else** — file-mutating tools (by tool name), PR-creation via a GitHub MCP tool (by tool name), and `git` branch/commit + `gh pr create` (best-effort Bash match) are denied; reads, read-only command/test execution, greps, subagents, and `gh issue` proceed; **no default-deny on an unclassifiable action** (ambiguity resolves to allow); **(3) the gate is a fallible §6 nudge, never the wall** — stated honestly that the platform ignores a `PreToolUse` deny for some edit paths ([D-051](0051-guardrail-integrity-the-builder-cannot-silently-weaken-its-o.md), verified), the [hooks](../spec/systems/infrastructure/hooks.md) fail-open law applies, and shell matching is best-effort, so the only unbypassable wall is the protected-branch merge; **(4) entry is a deliberate, announced, operator-only act** — the v1 Build-entry vehicle is an operator-only-invocable [skill](../spec/systems/surfaces/skills.md) (modes' own leaf), so the model cannot self-elect silently or by default; plan approval and an explicit "build this" are operator *cues* routing to that same entry, and modes does **not** depend on observing a plan-approval event (the platform does not reliably expose it); **(5) stance is operator-legible** (current stance, denials, and the Build entry all surfaced in plain language). A **Build-spec leaves** section fixes the residue (the stance-signal representation, the exact denied-action match list, the verb name/copy) so the locked doc implies no unresolved *design*. Modes is **pure core, no slot/filling** ([D-069](0069-core-module-seam-walk-the-demarcation-operationalized-glossa.md)).

## Why

Modes is the correct Wave-3 head: it reads only laws of its own plus the locked boot (grounding), hooks (block budget + fail-open), state (never-persisted), and skills (invocation axis); its only churning neighbors are *downstream* (close, build-orchestration), reduced to pure deferrals. The four-lens cold-session design audit ([D-018](0018-cold-session-design-audit-required-before-any-lock.md): adversarial / technical-feasibility / non-engineer-operator / architect, no shared context) ran against the plan **before** the lock and **materially reshaped it** — three blocking/serious findings drove design changes, not wording fixes: **(blocking, technical-feasibility)** `ExitPlanMode` plan-approval is **not reliably observable to hooks**, so the "approving a plan enters Build" trigger was **dropped as a mechanical event** and replaced by the operator-typed-verb entry with plan-approval as a cue only; **(blocking, adversarial)** [D-051](0051-guardrail-integrity-the-builder-cannot-silently-weaken-its-o.md) already *verified* the platform ignores a `PreToolUse` deny for some Edit/Write paths, falsifying any "tool-name legs reliable, only Bash best-effort" framing — so the gate is reframed as **uniformly fallible**, every leg a §6 nudge backstopped by the merge wall, no leg dressed as reliable; **(serious, non-engineer-operator)** the prior "deny anything not parseable as clearly safe by default" would block legitimate Explore work (test/build runs) and produce unexplained refusals — so the gate was **inverted to allow-by-default, deny-only-the-building-set**, with read-only command execution explicitly allowed and every denial a plain sentence naming the block and the way forward. Folded further: the stance signal is pinned **session-id-keyed in OS-temp** (the only "never-persisted"-honoring representation a stateless `PreToolUse` hook can read — a fresh session never reads a prior session's key), draining the adversarial "defaults-to-Explore-when-unreadable smuggles persistence" concern; the modes↔build-orchestration **circular ownership** of the trivial-write fast path was drained (modes keeps the entry *principle*; build-orchestration owns the *mechanism* and the Routine *workflow*), removing a latent re-lock trigger; the enumerated deny list and verb name were demoted to **build-spec leaves** (architect: law-vs-leaf); self-election is framed **visible-and-effortful, never "cannot"** (operator lens + §6). Technical-feasibility verified operator-only-invocation maps to a real skills `disable-model-invocation` value, `PreToolUse` `permissionDecision: deny` + tool-name matching, the un-parseable-shell limit, and the Actions-cron read-only-audit path. Propagation per the matrix: **no locked doc edited** (grep-verified); [scenarios/build-session.md](../architecture.md#build-session-lifecycle) fast-path link repointed modes→build-orchestration; [risks.md](../reference/risks.md) opens **R11** (the operator-typed-verb honor-rate quirk on the entry path — fail-safe to Explore, not fail-open); [glossary](../reference/glossary.md) "Mode (stance)" and [engine-architecture.md](../architecture.md) §7 verified still truthful (neither names a specific entry trigger; both already call the gate a strong-default-not-wall); [R6](../reference/risks.md) firmed, not closed.

## What we ruled out

Keep `ExitPlanMode` as a mechanical Build-entry trigger (rejected — the platform does not reliably surface plan-mode transitions to a hook, verified in the cold audit; depending on an unobservable event would silently strand the entry; plan approval is a cue routing to the operator-typed verb). Frame the gate's tool-name legs as reliable and only the Bash leg as best-effort (rejected — [D-051](0051-guardrail-integrity-the-builder-cannot-silently-weaken-its-o.md) verified the platform ignores a `PreToolUse` deny for some edit paths, so *every* leg is fallible; an asymmetric reliability claim is the over-claim §6/§7 forbid). Keep "deny any action not parseable as clearly safe" (rejected — it taxes the stance meant to be the comfortable default, blocks legitimate test/build runs, and yields unexplained refusals; the §6 nudge errs toward allow with the merge gate as the wall; the operator chose the precise deny-list). Persist stance across sessions (rejected — contradicts locked [state](../spec/systems/cognitive/state.md); a crashed Build must not resurrect as Build, guaranteed by session-id keying + absent-resolves-to-Explore). Claim the model *cannot* enter Build (rejected — §6 forbids dressing a local mechanism as an absolute wall; the honest tier is "cannot enter silently or by default" — visible-and-effortful, merge gate as the wall). Let modes own the trivial-write fast-path mechanism or the Routine workflow (rejected — that is [build-orchestration](../spec/systems/lifecycle/build-orchestration.md)'s; describing it twice would force a modes edit at build-orchestration's later lock). Freeze the enumerated denied-action list or the verb name in the locked doc (rejected — build-spec leaves; a locked doc fixes laws not leaves, the [D-060](0060-lock-the-knowledge-system-wave-2-the-purely-derived-structur.md)/[D-063](0063-lock-the-boot-orientation-system-wave-2-terminal-the-integra.md) precedent). Edit or re-lock any locked doc (rejected — every reference is a deferral *to* modes; honoring them changes none). Defer the modes lock (rejected — it is the Wave-3 head, anchored entirely on locked upstreams, with only downstream `designed` neighbors that depend on it).

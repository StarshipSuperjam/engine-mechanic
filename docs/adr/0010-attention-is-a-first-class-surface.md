# Attention is a first-class surface

*Decided 2026-05-22 in the design workspace.*

## The decision

Promote attention (boot-pack budget allocation + work prioritization + debt-blocking) to a named, contracted surface rather than emergent behavior.

## Why

Attention is what stops a cold AI from rabbit-holing or surfacing the wrong things first; it is the weakest cognitive leg when left as hardcoded constants.

## What we ruled out

Leave prioritization as static budget constants in boot code — rejected because it never matures and is invisible to governance.

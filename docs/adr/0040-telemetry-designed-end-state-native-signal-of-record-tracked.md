# Telemetry designed end-state: native signal-of-record; tracked debt is engine-labeled GitHub Issues

*Decided 2026-05-24 in the design workspace.*

## The decision

Settle [telemetry](../spec/systems/guardrails/telemetry.md)'s designed end-state. **Signal-of-record is native:** merged-PR CI pass/fail (read via `gh`) + **best-effort** ambiently-captured local check fires + the [memory](../spec/systems/cognitive/memory.md) ledger — **no bespoke check-fire ledger** and **no "validator emits PR outcome" capability** (locked [validation](../spec/systems/guardrails/validation.md)/[control-plane](../spec/systems/infrastructure/control-plane.md) untouched); the ambient log is best-effort, never complete, and no law treats it as a guarantee. A **stream** is a derived signal series over the native record carrying a severity class; the **stream cache is gitignored** (regenerable, [principle §2](../principles.md)). **Tracked debt/findings are engine-labeled GitHub Issues** (the locked finding-disposition "issue scaffold"); the **"debt register" is the view over open engine-labeled issues**, not a committed or gitignored file. **Triage is telemetry's one autonomous act:** open/update a deduped engine issue. **Promotion law:** severity-class sets latency (trust-critical — a gate/probe that could not run — promotes immediately; persistent-benign on a **persistence threshold held in a governed [policy](../spec/systems/surfaces/policies.md)**, the [R4](../reference/risks.md) lesson). **Auto-resolve** closes the issue when the signal stays clear for N observations — it clears the flag, it does not repair. Telemetry **emits the never-fired signal**; the retire/keep **judgment** is audits'. **Output home is system-owned non-surface:** the gitignored stream cache + the committed, fingerprint-gated **audit digest** (audits-owned); the [ontology](../spec/systems/grammar/ontology.md) is untouched (tier-4 observational needs no catalogued members). **This supersedes [D-031](0031-integration-debt-is-a-telemetry-owned-register-not-a-knowled.md)'s "committed, event-sourced register" *file* framing** — which was in latent tension with locked [topology](../spec/systems/infrastructure/repository-topology.md) law 5 ("canonical data is never a committed path"); D-031's debt-ownership (telemetry owns it; knowledge carries none) stands. Telemetry stays **`designed`** — a lock-candidate, not locked.

## Why

The interim "gitignore the findings log" model drifted from the **locked** finding-disposition policy, which already routes a logged finding to a control-plane **issue scaffold**; the cold-session multi-lens audit (adversarial/feasibility/operator/architect) ran against the plan and caught it. GitHub Issues are native ([D-038](0038-session-lifecycle-re-founded-on-native-substrates.md)), citable (auditability, [goals §4](../reference/goals-and-quality.md)), operator-visible, disk-loss-proof, and **upgrade-safe** (not files, so an engine overlay [D-024](0024-the-engine-is-upgradeable-versioned-packages-upgraded-by-ove.md) cannot touch them) — resolving the whole auditability/trust/backup/policy-conflict cluster at once. Native signal honors D-038 (no parallel bookkeeping) and adds no capability to any locked doc. Kept `designed` not `locked` because telemetry references the still-`designed` cognitive/lifecycle laws (attention surfacing, boot, build-orchestration) and the reworked persistence model should re-audit against the authored doc before ratifying.

## What we ruled out

A committed event-sourced register file (rejected — topology law 5 forbids committing canonical data, and it would collide with the engine overlay). A gitignored findings-log file as canonical (rejected — invisible to the operator, fails auditability §4, and conflicts with the locked finding-disposition issue routing). A bespoke check-fire ledger (rejected — rebuilds the dissolved session archive, D-038). A "validator emits structured PR outcome" capability (rejected — burdens locked validation/control-plane; native CI pass/fail + ambient capture + findings suffice). A catalogued `report` surface (rejected — pulls observational output into the knowledge-coverage machinery and needs a new derived-surface law in the locked ontology; system-owned non-surface is cleaner). Per-rule telemetry fields on every check (rejected — buried-constants sprawl; thresholds belong in a governed policy).

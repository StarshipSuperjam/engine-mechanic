# Decouple the locked agent grammar from the model landscape: `model-tier` becomes a closed *demand* vocabulary; the concrete model/effort realization moves to config

*Decided 2026-05-28 in the design workspace.*

## The decision

Make the locked agent grammar **model-agnostic and effort-value-agnostic** so a new model release (Opus 4.8 shipped today; Mythos is weeks out) is adopted by changing config, never by re-litigating a locked design — the operator's north star: *disconnect the model from the work*. **Re-litigate [D-057](0057-lock-the-agents-surface-wave-1-four-settled-design-forks.md) fork (3)** under the litigation-alarm protocol (operator-approved): the [agents](../spec/systems/surfaces/agents.md) `model-tier` field stays a **closed, coherence-checkable set** (fork (3)'s settled property is *preserved*), but its **members swap axis from model-identity to work-demand** — `{`opus`, `sonnet`, `haiku`}` becomes the demand vocabulary **`{`judgment`, `mechanical`}`** (the execution tier the work *demands*, never a model name). The field keeps the name `model-tier` (rename deferred to [Q21](../reference/open-questions.md)). The persona's **concrete execution realization = (`model` + `effort`)** is **persona-owned platform passthrough**: [agents](../spec/systems/surfaces/agents.md) adds **`effort`** alongside `model`/`tools`/`permissionMode` as a platform key the persona carries, and reframes the durable-alias wisdom as *guidance* (the platform `model` also accepts full-IDs and `inherit`, so the old enum was narrower than the platform), not a closed engine set. The engine governs only *that* a persona declares a `model-tier` demand level and the role/lens/permissions/output-contract grammar — **never which model exists**; roster derivation by `role`/`lens` ([§14](../principles.md)) is untouched. **[build-orchestration](../spec/systems/lifecycle/build-orchestration.md) re-litigated** (same protocol): the worker delegation rationale is corrected — workers run the `mechanical` demand tier, the orchestrator/reviewers run `judgment`, and the **load-bearing rationale is unchanged** (delegation buys **cohesion under context pressure** — generation kept out of the orchestrator's window so it authors one cohesive set, output checked at Integrate, semantic-overlap reconciliation real bounded work). The **falsified cost economics is severed**: the old "this step justifies a *cheaper* worker tier (its output is checked)" is now causally wrong (a cheaper, flawier worker can *raise* the orchestrator's costly rework, since the [Opus-vs-Sonnet] cost gap collapsed to ~1.67× and the higher-quality model leaves materially fewer flaws); Integrate checks worker output for fit/correctness **regardless of cost**, and **whether the worker's realization should be lower-cost is a config-time judgment that can go either way** — explicitly not a design lock. A **worker execution-realization (model + effort) build-spec leaf** is added (a config/authoring concern: a `mechanical` worker's realization is carried in its own **agent-definition frontmatter** — `model` + `effort`; unlike `model`, `effort` has no per-spawn override, so the worker's effort is pinned in the persona file rather than set per-spawn), with a note that this floor feeds the operator-facing cost-and-time estimate calibration so the consent surface stays truthful as the floor churns. **The north star is operationalized via glossary + this entry, NOT a new principle** — following the [D-069](0069-core-module-seam-walk-the-demarcation-operationalized-glossa.md) false-genus precedent (a "§17 bind-to-demand" peer principle would restate [§1](../principles.md)/[§14](../principles.md)/[§16](../principles.md) for a subset of cases): [glossary](../reference/glossary.md) gains **Execution profile** (the concrete model+effort realization a persona declares to satisfy its `model-tier` demand level; persona-owned, platform-passthrough, churns without touching a locked doc). **Dynamic Workflows** (research preview) is **design-for, guard-as-preview** — *not* hard-depended-on and *kept out* of the locked docs (their mechanism prose is already substrate-agnostic — "isolated worktree," Agent-spawned workers); the GA fallback is the current Agent-tool + `isolation: worktree` worker mechanism. The churning specifics live in [Q21](../reference/open-questions.md) (current realization binding + DW-adoption thread + the `model-tier` rename) and the preview-dependency in [R12](../reference/risks.md). `python3 lock.py --relock systems/surfaces/agents/README.md --decision D-100` then `python3 lock.py --relock systems/lifecycle/build-orchestration/README.md --decision D-100`; ratified_by D-100.

## Why

The design was **already built for model-agnosticism** — `model-tier` is persona-owned and the roster derives from `role`/`lens`, not the model ([D-057](0057-lock-the-agents-surface-wave-1-four-settled-design-forks.md), [§14](../principles.md)) — so the only coupling was **editorial**: two locked docs editorialized about *today's* models (the enum + "(Opus judgment, Sonnet mechanical work)"; "a cheaper worker tier"). The cold audit of the plan sharpened two points beyond cleanup: **(1)** removing the model names is a genuine **re-litigation of [D-057](0057-lock-the-agents-surface-wave-1-four-settled-design-forks.md) fork (3)** (whose anti-choice rejected opening `model-tier` "like `lens`"), so the alarm was raised by name and the operator chose the **minimal** reversal — keep the closed/checkable set, swap only its axis (model→demand) — rather than the fully-open free-prose tier that fork (3) already refused; **(2)** the retained Integrate rationale was **causally false**, not just mis-worded — the cost gap that made "cheap-generate / expensive-check" a win collapsed, so the economics is severed and worker delegation re-grounded **purely on cohesion under context pressure** (model-independent, from [D-073](0073-lock-build-orchestration-wave-3-terminal-and-re-litigate-con.md)). Grounded platform facts (verified against current Claude Code docs, hedged where sources are weak): Opus 4.8 regular $5/$25 vs Sonnet 4.6 $3/$15 (~1.67×); the higher-quality model leaves materially fewer flaws *qualitatively* (Anthropic's framing — **no** public quantified "Nx" figure, so none asserted); `model` is a per-subagent frontmatter key (`opus`/`sonnet`/`haiku`/full-ID/`inherit`) **with** a per-spawn override, whereas `effort` (`low`…`max`) is settable in agent-definition frontmatter / settings / `--effort` / `/effort` / env but has **no per-spawn override** — so a `mechanical` worker's effort is pinned in its persona file, not chosen per-spawn (the asymmetry, not a blanket "frontmatter-only" limit); `isolation: worktree` is native; Dynamic Workflows is a real research preview whose context-window-isolation mechanism *is* in primary Anthropic docs, but whose `workflow.js` filename is **secondary-source and uncorroborated** (flagged, not relied on). Per [D-071](0071-re-lock-modes-doc-level-cold-audit-corrects-an-as-written-re.md), the **as-written** relocked docs each got their own four-lens cold audit ([D-018](0018-cold-session-design-audit-required-before-any-lock.md)) before the relock, not only the plan; that audit caught and fixed a fabricated platform limit (an over-stated "`effort` is frontmatter-only / no per-spawn arg" claim — corrected to the model/effort asymmetry above), added the operator-facing cost-estimate **re-calibration obligation** as a posture-tier guarantee on the worker leaf, and added the [D-100](0100-decouple-the-locked-agent-grammar-from-the-model-landscape-m.md) citation to the [agents](../spec/systems/surfaces/agents.md) `model-tier` bullet; all blocking/serious findings were resolved before the relock. Propagation per the matrix: [agents](../spec/systems/surfaces/agents.md) + [build-orchestration](../spec/systems/lifecycle/build-orchestration.md) relocked; [glossary](../reference/glossary.md) Execution profile added + Persona template reconciled (field name retained); [open-questions.md](../reference/open-questions.md) Q21 added; [risks.md](../reference/risks.md) R12 added; this entry. **Verified no-touch:** [systems/guardrails/audits/README.md](../spec/systems/guardrails/audits.md) (LOCKED) lists the persona template's field **names** only and `model-tier` is preserved as a name → no edit, no relock; [principles.md](../principles.md) (no §17, per [D-069](0069-core-module-seam-walk-the-demarcation-operationalized-glossa.md)); [engine-architecture.md](../architecture.md) + [scenarios/](../architecture.md#build-session-lifecycle) (grep-confirmed no model name or model-tier rationale leaks — every other "tier" is team/authority/enforcement/paid/scanning); [modules/README.md](../reference/module-catalog.md) (no worker persona module exists — workers are orchestrator-spawned, so the realization is a spawn/config concern).

## What we ruled out

**Flip the enum to `{opus}` / bake an Opus floor into the locked design** (rejected — re-pins the design to a specific model, the exact treadmill the north star escapes; a Mythos release would force another relock). **Open `model-tier` to free-prose like `lens`** (rejected — the [D-057](0057-lock-the-agents-surface-wave-1-four-settled-design-forks.md) fork (3) anti-choice shape; loses the coherence-check that an instance's tier is a recognized value — the operator chose the closed demand vocabulary precisely to keep that property). **Add `effort` as a 6th canonical routing field** (rejected — expands the locked persona-template set and ripples to glossary/audits/[D-057](0057-lock-the-agents-surface-wave-1-four-settled-design-forks.md); `effort` is platform-passthrough realization, not engine-governed routing — it rides the same passthrough lane as `model`). **Mint a §17 "bind to the work demand, not the model" principle** (rejected — the [D-069](0069-core-module-seam-walk-the-demarcation-operationalized-glossa.md) false-genus precedent: it would restate [§1](../principles.md)'s committed-vs-out-of-repo split, [§14](../principles.md)'s derive-don't-pin, and [§16](../principles.md)'s relay-don't-own for the single execution-binding case; the disciplined home is a glossary term + this entry, lower blast radius — the operator's call). **Keep the "cheaper tier, output is checked" economics** (rejected — causally wrong now: a cheaper, flawier worker increases the orchestrator's costly rework; the honest rationale is cohesion-under-context-pressure, with cost a config-time judgment). **Adopt Dynamic Workflows as the primary parallel substrate now** (rejected — research preview; design-for and keep the Agent-tool + `isolation: worktree` GA fallback, naming no preview feature in a locked doc). **Assert "~4× fewer flaws"** (rejected — not a quantified public figure; only the qualitative direction is sourced). **Rename `model-tier` this pass** (rejected — high propagation to glossary/audits/[D-057](0057-lock-the-agents-surface-wave-1-four-settled-design-forks.md); deferred to [Q21](../reference/open-questions.md)).

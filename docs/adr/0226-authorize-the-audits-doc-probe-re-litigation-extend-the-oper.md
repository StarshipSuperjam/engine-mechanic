# Authorize the audits doc-probe re-litigation: extend the operator-communication-law judgment to operator-facing tool strings

*Decided 2026-06-21 in the design workspace.*

## The decision

Litigation alarm, on explicit operator approval (the approved plan), to edit the **locked** [audits](../spec/systems/guardrails/audits.md) doc (last re-locked by [D-216](0216-resolve-the-d-215-operator-prose-register-re-litigation-land.md)). [D-225](0225-recenter-the-spec-on-the-ai-is-the-thing-made-trustworthy-re.md) removed the mechanical word-bans that were the only signal watching the engine's operator-facing **tool** renderers; the audits cold-context doc-probe — the standing post-v1 judgment tier — read only the `doc` surface, so without an extension "jargon is audit-tier" would be **false for tool output** (the gap the operator-lens cold audit named). Authorize extending the doc-probe's remit to **operator-facing prose wherever authored** — a doc, *or* the operator-facing strings an engine tool renders — judging the **register** edge and the **substance** edge's clarity-over-jargon facet as semantic judgment, never a mechanical filter; disposition routed by ownership (project-authored local prose → local reconcile; template-owned tool string (machinery) → escalate-upstream), with the probe's **sampling** nature named honestly. Resolved in [D-227](0227-resolve-the-d-226-audits-re-litigation-landed-text-cold-audi.md).

## Why

The operator-communication law governs *all* operator-facing surfaces; tool output is one. Closing the gap in the law's standing judgment tier requires the audits doc to say so, and audits is locked — so the alarm is the honest path, not a silent edit. Feasible: tool operator-strings live statically in committed `.engine/tools/` source the cold probe already reads as an artifact.

## What we ruled out

**Realize the tool-string judgment only in the live engine-template audit persona, leaving the spec silent** (rejected — spec/build would diverge; the spec is source authority). **Leave jargon-in-tool-output unguarded post-v1, relying on build-conformance alone** (rejected — build-conformance retires at v1; the standing post-v1 tier would have a hole, [R30](../reference/risks.md)). **Add a mechanical tool-string filter instead** (rejected — that is the banned-word-list anti-pattern [D-225](0225-recenter-the-spec-on-the-ai-is-the-thing-made-trustworthy-re.md) just removed).

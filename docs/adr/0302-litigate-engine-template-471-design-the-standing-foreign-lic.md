# Litigate engine-template #471: design the standing foreign-`LICENSE`-seed detector (R29 residual / D-222 build-owe #5); edit four locked docs (not re-locked here); reserve the re-locks

*Decided 2026-07-12 in the design workspace.*

## The decision

This entry is the **litigation alarm + operator authorization** (direction confirmed in-session over `AskUserQuestion` + `ExitPlanMode` before any locked-doc edit) **and the design of record** for the **standing foreign-`LICENSE`-seed detector** — the undefined [R29](../reference/risks.md) residual / [D-222](0222-resolve-the-d-221-first-run-license-clear-re-litigation-land.md) build-owe #5 routed for litigation by engine-template [#471](https://github.com/StarshipSuperjam/engine-template/issues/471). The one-time first-run LICENSE clear ([D-221](0221-authorize-the-first-run-license-clear-re-litigation-reconcil.md)/[D-222](0222-resolve-the-d-221-first-run-license-clear-re-litigation-land.md)) is built; this designs the **standing** catch for a repo generated **before** the clear shipped, or that **drifted** the seed back into the slot. **Shape:** a boot-invoked, offline, consent-gated detect-and-offer — the [R20](../reference/risks.md) stranded-checkout pattern — provisioning owns the mechanism, [boot](../spec/systems/lifecycle/boot.md) surfaces and offers, the operator consents. **Core resolutions:** (1) **self-seed recognition** — the detector fires on the engine's **own** shipped template-license seed, never "a copyright that isn't the operator's," dissolving #471's stated blocker (the engine holds no notion of the operator's legal identity, only its own seed — a build constant); (2) **historical seed-set** (B1) — because a repo running the detector has necessarily upgraded past its generation-era seed, the recognizer matches the **append-only set of all historically-shipped seeds**, not just the current one, else it is blind to the pre-clear population it exists for; (3) **per-era distinctive-author anchor** (B2) — the conjunction's discriminating leg is the copyright-holder line under a holder-bearing license (MIT era) or the **Commons Clause licensor/product field** under the current Apache-2.0 + Commons Clause seed ([D-295](0295-engine-template-s-own-license-moves-mit-apache-2-0-commons-c.md)), whose Apache body is holder-less boilerplate — a correction that also **repairs a latent gap in the already-built first-run clear** (its spec named a copyright-line the Apache seed lacks); (4) **scope = LICENSE-only** — the marketing-README sibling ([R26](../reference/risks.md)) arm is dropped as [R6](../reference/risks.md) over-build (cosmetic, operator-visible, operator-correctable, first-run-mitigated, and never named a standing remedy); (5) **decline behavior = intent-exit** — a plain decline collapses to a terse standing line (never fully silent), while an explicit *kept-on-purpose* acknowledgment retires the finding, scoped to findings with a legitimate operator-intended terminal state (never a governance alarm). **The legal gate is removed** by [D-301](0301-close-q41-by-decision-decline-legal-input-on-commons-clause.md) (Q41 closed won't-pursue), so re-locking the clear model no longer stands over an open legal question.
  **Locked docs edited under this entry — NOT re-locked here (four):** [repository-topology](../spec/systems/infrastructure/repository-topology.md) (law 2 gains a narrow consent-gated standing exception to "reconciles once at instantiation / preserved on later overlay"), [modules/core](../spec/modules/core.md) (the detector added to `provides`; an integration bullet; the never-strand-main "one exception" generalized to the operator-consented, boot-offered corrections of the engine's own residue), [provisioning](../spec/systems/infrastructure/provisioning.md) (build-owe #5 → designed standing-detector section; recognizer reconciled to per-era anchor + historical seed-set; the "not the operator's" phrasing corrected to self-seed), [boot](../spec/systems/lifecycle/boot.md) (the leftover-license surfacing bullet + provenance framing + the kept-on-purpose intent-exit in the anti-habituation ledger). **`validate.py` flags exactly these four fingerprints until the re-locks**, which land in dependency order (topology → core → provisioning → boot) under **forward-reserved D-303–D-306** (one resolve/re-lock entry per carrier, the [D-293](0293-resolve-re-lock-build-orchestration-roster-divergence-hunter.md)/[D-300](0300-resolve-re-lock-contracts-the-two-eadr-populations-named-can.md) per-carrier precedent) **after the mandatory landed-text four-lens cold audit**.

## Why

the standing detector invents no grammar — it reuses the R20 detect/surface/consent pattern, the existing `tools` surface, boot's open-findings channel and presentation ledger, and the first-run clear's recognizer + disclosure. Self-seed recognition is strictly more robust than the naive identity-guess the locked residual text gestured at (the engine cannot know the operator's legal identity but always knows its own seed). Correcting the recognizer to a per-era historical anchor is owed regardless of #471 — it fixes the built clear under the [D-295](0295-engine-template-s-own-license-moves-mit-apache-2-0-commons-c.md) seed. Homing the write authority in topology law 2 (the ownership anchor) + core (the tool + never-strand-main floor) keeps the seam where the strand detector already lives.

## What we ruled out

**Recognize "a copyright holder that is not the operator's"** (rejected — the engine holds no notion of the operator's legal identity; self-seed recognition of its own build-constant seed is robust and needs no identity model). **Current-seed-only recognizer** (rejected — blind to the pre-clear population, the detector's whole target; B1). **Keep the README arm** (rejected — [R6](../reference/risks.md) over-build; [R26](../reference/risks.md) is cosmetic, operator-correctable, first-run-mitigated, and never named a standing remedy). **Collapse-only "never fully silent" for the LICENSE finding** (rejected — a category error: a deliberately-kept license has a legitimate terminal state governance alarms lack, so it would nag forever; the intent-exit fixes it while keeping the plain-decline never-fully-silent posture for un-acknowledged leaks). **Additive-only edit leaving the "not the operator's" residual text in place** (rejected — a locked-doc self-contradiction; reconciled in place). **Leave topology law 2 / modules/core verify-no-edit** (rejected — a standing post-instantiation product-root write needs a declared authority those two docs alone can give; the smaller first-run clear itself re-locked topology, so a larger standing touch cannot lean verify-no-edit). **Gate the litigation on Q41 legal input** (rejected — the input will never come for an experimental no-revenue repo; Q41 closed by decision, [D-301](0301-close-q41-by-decision-decline-legal-input-on-commons-clause.md)). **Auto-clear the LICENSE without consent, or a daemon** (rejected — [§8](../principles.md); a boot-invoked read-only detector + consent-gated fix, the accepted R20 shape). **Re-lock the four docs in this entry** (rejected — the landed-text cold audit is the HARD gate before the irreversible re-lock; the re-locks land under [D-303](0303-resolve-re-lock-repository-topology-law-2-gains-the-standing.md)–[D-306](0306-resolve-re-lock-boot-the-leftover-license-surfacing-the-hook.md) after it). **Fold the four re-locks into one resolve entry** (rejected — the [D-293](0293-resolve-re-lock-build-orchestration-roster-divergence-hunter.md)/[D-300](0300-resolve-re-lock-contracts-the-two-eadr-populations-named-can.md) per-carrier precedent gives each re-locked doc its own fingerprint-bearing record).

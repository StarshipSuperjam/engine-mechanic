# Take up Q17 component (a): authorize a five-foundation re-litigation for a per-project operator-override of policy tuning values

*Decided 2026-06-04 in the design workspace.*

## The decision

On the operator's call, **take up component (a) of [Q17](../reference/open-questions.md) now** — the determinism-safe, per-project **operator-override of policy tuning values that survives an engine overlay** — superseding [D-166](0166-triage-engine-template-issue-42-per-project-attention-tuning.md)'s deferral of (a). Component (b) (telemetry-driven auto-calibration) **stays parked** (no deployment evidence to calibrate from; collides with attention's locked determinism). This entry is the **litigation alarm + authorization**; it authorizes editing five locked foundations, and the **re-locks land under the resolve entry** after the mandatory cold audit on the landed text. **Final design (a four-lens cold plan-audit reworked it):** the override is a **committed operator-config file preserved across overlays** — the [memory](../spec/systems/cognitive/memory.md) backup-pointer precedent ([topology](../spec/systems/infrastructure/repository-topology.md) law 5, "configuration is not data"), **not** a foundation-infrastructure artifact (that is the overlaid-wholesale engine-owned category); absent until the operator first sets a value. **Scope = tunable values only, excluding structural fields:** eligible are attention's budget splits, intra-partition weights, debt-blocking + scent thresholds and triage-threshold's persistence/auto-resolve/triage-pressure; **not** eligible are attention's partition **precedence and trim order** (they encode the structural laws — "blocking-debt-first" stays inviolable by construction) nor any enforcement/guardrail config. **Sparse per-key merge at read time;** a stale key (gone after an upgrade) falls back to the default and is surfaced — **no** version-stamp/backup-first machinery (that pattern is for gitignored data; a committed override reverts with git). **Validation** = the policy's own generic schema + the consumers' existing defensive normalization (budgets renormalize as today), plus a rule instance flagging stale keys — existing kinds, **no validation re-lock**. **Determinism preserved** — a static operator value is another recorded input to [attention](../spec/systems/cognitive/attention.md)'s pure function, so **attention is not re-locked**; [telemetry](../spec/systems/guardrails/telemetry.md) reads the effective value (§16 relay) and [boot](../spec/systems/lifecycle/boot.md) surfaces drift on its existing channel — **neither re-locked**. **Authoring = a thin operator-typed command in v1** (engine shows the effective value → operator picks → validate → write + commit → confirm) plus a reactive retune offer; engine-mediated, never hand-edit ([constraints](../reference/constraints.md)). The merge-mechanism is **core**; the command is a **v1 required** operator-typed skill. **Re-lock set (5, landing under the resolve entry):** [policies](../spec/systems/surfaces/policies.md), [repository-topology](../spec/systems/infrastructure/repository-topology.md), [provisioning](../spec/systems/infrastructure/provisioning.md), [module-system](../spec/systems/grammar/module-system.md), [audits](../spec/systems/guardrails/audits.md). **Non-locked propagation:** rewrite Q17 to "(a) designed-in, only (b) parked"; reconcile [R6](../reference/risks.md)/[R7](../reference/risks.md); [glossary](../reference/glossary.md); [engine-architecture](../architecture.md) §3; [scenarios/upgrade-the-engine](../architecture.md#upgrading-the-engine); [modules/core](../spec/modules/core.md) + the skills/operations surfaces for the authoring command. `python3 validate.py` green at each step.

## Why

(a) is determinism-safe (a static input — no decay store, no learning), needs no usage evidence, and completes the "tunable" capability the [attention](../spec/systems/cognitive/attention.md)/[policies](../spec/systems/surfaces/policies.md) docs already advertise; it is separable from and a prerequisite to (b) ([D-166](0166-triage-engine-template-issue-42-per-project-attention-tuning.md)). Taking it up **now** is the cheapest point — the foundations it touches are mostly unbuilt and there are zero deployments to migrate; post-v1, every deployed instance would need migration. This is a **justified re-litigation, not silent drift** — the lock stops drift, not warranted edits — and the four-lens cold plan-audit reworked the design before this authorization (correcting the artifact mis-classification, the validation over-claim, the over-built drift machinery, the missed Q17 propagation, the audits seam, and the hand-edit v1 path), so what is authorized here is the audited design, to be re-audited on the landed text before the re-locks.

## What we ruled out

**Defer (a) too** (rejected by the operator — (a) is a present, certain v1 limitation in every deployment, determinism-safe, cheapest to seat now). **Take up (b) as well** (rejected — no deployment evidence to calibrate from; collides with attention determinism; [§12](../principles.md)/[R6](../reference/risks.md) keep speculative self-tuning out of core). **Classify the override file as a foundation-infrastructure artifact** (rejected per audit — that is the overlaid-wholesale category; it is preserved operator config). **Hand-edit as the v1 authoring path** (rejected — violates [constraints](../reference/constraints.md); the engine-mediated command is the entry point). **Make precedence/trim override-eligible or gate-enforce cross-field invariants** (rejected — excluding the structural fields keeps the safety laws inviolable by construction and needs no new validation). **Version-stamp/backup-first migration** (rejected — that pattern is for gitignored data; a committed override reverts with git). **Whole-thing-as-a-module to dodge the re-litigation** (rejected — the merge consumers and the preserved-vs-overlaid partition are core foundation grammar; modularizing cannot reach them without the same re-litigation).

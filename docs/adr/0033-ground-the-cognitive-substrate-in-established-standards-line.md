# Ground the cognitive substrate in established standards (lineage, honest novelty, leak guard)

*Decided 2026-05-24 in the design workspace.*

## The decision

Cite the cognitive substrate's lineage in the established field rather than implying homegrown novelty. **(1) Formal vocabulary:** the substrate **follows the CoALA taxonomy** (working memory = the boot pack / orientation context; episodic = [memory](../spec/systems/cognitive/memory.md); semantic = [knowledge](../spec/systems/cognitive/knowledge.md); the decision-making procedure = modes + attention + boot) — as taxonomy lineage, never an implementation spec; CoALA leaves semantic-memory representation open, which licenses the swappable index. **Attention** is the prioritization piece of **context engineering** (the orientation family as a whole instantiates that discipline). CoALA's "procedural memory" is **not** mapped to the surfaces as an equivalence — that is a category error (CoALA's procedural memory is the agent's action policy, not the authored-artifact catalog), so it is at most a hedged, illustrative footnote and the surfaces are never renamed. **(2) Inspiration:** the [scent](../spec/systems/lifecycle/boot.md) cites **active / forward-looking retrieval** (FLARE retrieves on low-confidence tokens within an anticipated future sentence; the scent differs by triggering on a lexical match against the user prompt); [memory](../spec/systems/cognitive/memory.md) cites mempalace-class heritage, rejecting mem0-style write-time extraction. **(3) Roadmap:** the 2025–26 graph-memory frontier (MAGMA, MemOS, SYNAPSE) is recorded as arXiv-pinned swap-in watch-items in **[open-questions](../reference/open-questions.md) only** ([Q11](../reference/open-questions.md)) — durable docs name only the swappable seam, so they never rot against the deletion mandate. **(4) Honest novelty (canonical statement, quoted verbatim in [engine-architecture.md](../architecture.md) §4 and the glossary):** *The cognitive substrate introduces no novel taxonomy — its shape follows the CoALA cognitive-architecture, its prioritization is context engineering, and its push is active / forward-looking retrieval. The genuine contributions are two: (a) the repo-native delivery + trust model — committed-files, degradable, GitHub-template, non-engineer-operated — which the SDK/research field is not addressing; and (b) specific integration choices that depart from the cited patterns: the push-not-pull scent ([D-029](0029-cognitive-substrate-is-one-workflow-a-2-store-1-register-1-c.md)) and observe-don't-predict, usage-derived salience ([D-030](0030-memory-ledger-canonical-observe-don-t-predict-capture-lexica.md)).* **(5) Leak guard:** this lineage vocabulary is maintainer-layer framing only — like "microkernel-inspired" ([D-025](0025-fault-containment-is-earned-at-the-seams-not-conferred-by-mo.md)) it must never surface in operator-facing surfaces or runtime narration. Opens Risk [R8](../reference/risks.md) (conditional hub-explosion).

## Why

Standing in named, traveled lanes stops the design from re-deriving solved framing badly and from claiming creativity it lacks; citing inspiration is intellectual honesty and an onboarding aid. The four-lens cold audit verified the citations against current sources and corrected three would-be errors before they landed — a fabricated CoALA quotation, the procedural-memory category error, and a missing leak guard — and caught an over-correction (an earlier draft's "no cognitive novelty" erased the genuine [D-029](0029-cognitive-substrate-is-one-workflow-a-2-store-1-register-1-c.md)/[D-030](0030-memory-ledger-canonical-observe-don-t-predict-capture-lexica.md) contributions), so the novelty claim is narrowed to *taxonomy* while preserving the real integration novelty. Confining churning frontier names to the deletion-on-resolution parking lot honors the authored-complete-today rule; the field grounding (CoALA, context engineering, FLARE, the graph-memory frontier) was verified against current sources.

## What we ruled out

Keep the homegrown vocabulary uncited (rejected — implies false novelty and ignores traveled lanes, the operator's stated objection). Adopt CoALA/frontier machinery wholesale or rename surfaces to the standard's terms (rejected — cargo-culting and a layer-discipline violation; cite vocabulary, import no machinery). Map CoALA procedural memory onto the surfaces (rejected — category error). Name frontier systems across the durable docs (rejected — they churn and would rot against the deletion mandate; confine to open-questions). Claim "no cognitive novelty, only delivery" (rejected — under-claims and contradicts D-029/D-030). Let lineage jargon reach operator surfaces (rejected — the same leak D-025 forbids for "microkernel").

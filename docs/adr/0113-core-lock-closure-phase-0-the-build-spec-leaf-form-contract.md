# Core-lock closure Phase 0: the build-spec-leaf form/contract convention refinement + the canonical `finding.v1` base

*Decided 2026-05-29 in the design workspace.*

## The decision

Settle the two core-lock-closure Phase-0 cross-cuts ([D-112](0112-author-the-core-lock-closure-procedure-the-q24-q27-remediati.md)) that fix the content of multiple per-doc edits in the closure wave; both touch **no locked doc**, so neither is a litigation-alarm event. **(1) The Q27 meta-convention** is recorded as a **refinement of the laws-not-leaves convention** ([D-052](0052-foundational-law-layer-closed-the-implementation-lock-order.md)/[D-003](0003-specify-the-full-end-state-before-the-first-build-pr.md)): *a build-spec leaf may defer concrete values, but must pin (or explicitly home) the form/contract those values inhabit.* It is **not** homed in [principles](../principles.md) §10 — §10 governs ontology-precedes-surface-instance authoring, a different concern from deferral discipline within an already-authored design; grafting it there would strain the principle, is the change-propagation matrix's highest-blast-radius edit, and the [D-069](0069-core-module-seam-walk-the-demarcation-operationalized-glossa.md)/[D-100](0100-decouple-the-locked-agent-grammar-from-the-model-landscape-m.md) false-genus precedent rejects elevating a refinement to its own principle. The convention lives here, cited like the convention it refines. **(2) The canonical finding shape** is **`finding.v1`** = `{severity, message, location ref (file/line)}`, the **extracted common base** of the already-locked [agent](../spec/systems/surfaces/agents.md) `output-contract`. Consumers reference it: the [check](../spec/systems/surfaces/check.md) kind-callable result wraps it in a pass/fail verdict ([Q27](../reference/open-questions.md) #1); [telemetry](../spec/systems/guardrails/telemetry.md)'s finding-record extends it (`+ source-id + first/last-seen markers`, Q27 #4); the agent `output-contract` **remains its own locked, `.v1`-versioned, fixture-tested instance that profiles `finding.v1`** (severity narrowed to `blocking|serious|nit`) — **no field-reference change in the agents doc, so agents does not re-lock**. **Severity is a per-consumer enum** over the shared structural base (review `blocking|serious|nit` vs check `tier hard|soft` vs telemetry severity-class `trust-critical|persistent-benign` — genuinely different axes) and a **backstage, never-rendered field**: operator-facing surfaces translate to plain language (the [§12](../principles.md)/[§14](../principles.md)/[§16](../principles.md) leak guard restated at the base so the shared field is not a leak vector). `finding.v1` is a free-standing shared schema **homed on the [schemas](../spec/systems/surfaces/schemas.md) surface**, referenced by consumers' governing schemas via JSON-Schema-2020-12 `$ref`/`allOf` — an **additive instance, not a grammar change, so schemas does not re-lock**. The applications to `check`/`validation` and `telemetry` are the alarm-gated wave steps; this entry only fixes the base and home. A new [glossary](../reference/glossary.md) term records `finding.v1`.

## Why

[D-112](0112-author-the-core-lock-closure-procedure-the-q24-q27-remediati.md)'s procedure made deciding these two cross-cuts first a precondition (each fixes the content of several per-doc edits, so deciding them after a relock would force re-opening it). The operator decided both this session and a four-lens cold plan audit (adversarial · technical-feasibility · non-engineer-operator · architect, cold-context, the plan inlined) ran against the closure decisions before this entry. Technical-feasibility verified firsthand (current Claude Code / MCP / JSON-Schema-2020-12 docs) that a shared versioned schema referenced by multiple consumers via `$ref`/`allOf` is idiomatic, and that a check-kind callable returning a pass/fail wrapper over a shared finding base fits the locked thin-dispatcher model. The **§10-vs-laws-not-leaves home** was itself an audit finding (architect lens): the §10 graft strains the principle and carries the matrix's highest blast radius, so the operator re-decided to the laws-not-leaves home. The **no-agents-re-lock / no-schemas-re-lock** claims were stress-tested (adversarial lens) and hold **only** under the extracted-common-base construction pinned above (agents keeps its own conforming `.v1` with no field-reference change; schemas gains an additive instance); a construction that repointed the agent schema **would** be an agents alarm and is rejected. The **never-rendered severity** guard answers the operator lens's finding that a shared `severity` field invites raw rendering of three divergent backstage vocabularies into operator-facing artifacts. No locked doc is edited by this entry. Propagation: [glossary](../reference/glossary.md) gains the `finding.v1`/canonical-finding term; the closure wave applies the base at the `check`/`validation` and `telemetry` steps; [open-questions.md](../reference/open-questions.md) Q27 #1/#4 close when those steps land (Q27 deletes only after all five instances close); this entry. `validate.py` green.

## What we ruled out

Home the meta-convention in [principles](../principles.md) §10 (rejected on audit — strains §10's surface-authoring scope, highest blast radius, against the [D-069](0069-core-module-seam-walk-the-demarcation-operationalized-glossa.md)/[D-100](0100-decouple-the-locked-agent-grammar-from-the-model-landscape-m.md) refinement-is-not-a-principle precedent; the operator re-decided to laws-not-leaves). Mint a new principle §17 for it (rejected — same false-genus precedent). Adopt `finding.v1` by **repointing** the agent `output-contract` schema to a foreign id (rejected — a field-reference change in a locked doc, an agents litigation alarm; the extracted-common-base + profile construction keeps agents locked-as-is). Force one **uniform severity vocabulary** across agents/checks/telemetry (rejected — the three axes genuinely differ; a shared structural base with a per-consumer severity enum is the honest shape). Render `severity` to the operator (rejected — backstage-only; operator surfaces translate to plain language). Home `finding.v1` by pinning it inside `check`/`validation` and referencing it from telemetry (rejected — a payload shared by ≥2 consumers belongs on the [schemas](../spec/systems/surfaces/schemas.md) surface, not reached across a surface boundary into one consumer's internals). Defer the finding shape to the per-doc steps (rejected — [D-112](0112-author-the-core-lock-closure-procedure-the-q24-q27-remediati.md): the cross-cut fixes the content of both the check and telemetry edits; deciding it once avoids a cross-doc contradiction).

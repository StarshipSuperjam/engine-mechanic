# Authorize the operator-prose-register re-litigation: sharpen the operator-communication law as a rubric and give it teeth in the audit doc-probe (condescending getting-started.md)

*Decided 2026-06-18 in the design workspace.*

## The decision

Authorize a re-litigation (litigation alarm) on explicit operator approval to (a) sharpen the **operator-communication law** with an explicit register/respect clause and (b) extend the [audits](../spec/systems/guardrails/audits.md) cold-context doc-probe to judge that register — touching locked [surfaces/docs](../spec/systems/surfaces/docs.md) and [audits](../spec/systems/guardrails/audits.md), plus the canonical law definition in the (non-locked) [glossary](../reference/glossary.md). **The litigation alarm:** the operator, reading the engine-template build's `docs/getting-started.md`, found it **condescending — "talking down to a child."** Grounding found the [docs surface](../spec/systems/surfaces/docs.md) (locked, [D-055](0055-collapse-command-into-the-skill-surface-invocation-is-a-gove.md)) already carries the operator-communication law ("clear and complete... **never dumbed down and never engineer-shorthand**"), so the condescending doc is a **build-conformance miss against an existing standard, not a planning gap** (filed as a build-owes, below). The deeper finding: that standard is **posture without teeth** — the build authored a doc violating it and **no gate fired**, because the law's only enforcement, the audits cold-context doc-probe ([posture law 3](../spec/systems/guardrails/audits.md)), judges a doc's **truth and usefulness** ("does it tell a cold consumer how to *use* it?") but **not its register** — a condescending-yet-accurate-and-usable doc passes.

  **The decision — the operator's "law-as-rubric + audit teeth", not words alone.** A four-lens cold plan-audit pushed back that sharpening the law's wording *alone* would be **posture the build can ignore exactly as it ignored "never dumbed down"**, and risks the [D-192](0192-authorize-the-conduct-surface-codes-of-conduct-a-tier-3-pros.md) mis-promotion caution (a single bad instance inflated into corpus law). The operator's chosen resolution defeats both objections by making the clause *do work*:
  - **The law clause becomes the rubric, not a restatement.** Sharpen the operator-communication law ([glossary](../reference/glossary.md) canonical + the [docs surface](../spec/systems/surfaces/docs.md) restatement) with a bounded **register/respect clause**: address the operator as the capable adult they are — never condescending, never a register pitched below them, never padding the obvious; respect for the reader's intelligence is part of clarity, and completeness is not license to over-explain. This is a *register* standard distinct from the existing *substance* standard ("never dumbed down" = do not hide substance), not a synonym for it.
  - **The audit probe gets the teeth.** Extend the [audits](../spec/systems/guardrails/audits.md) cold-context random-target **doc-probe** (posture law 3) so that, reading an operator-facing artifact as a cold consumer, it also judges **register against the rubric** — a doc that talks down to the operator **fails the probe**, even when accurate and usable. The standard now bites where it did not.

  **Scope. Re-lock set — 2** (both currently locked → re-locked, none added): [surfaces/docs](../spec/systems/surfaces/docs.md) (the operator-communication-law restatement gains the register clause, framed as the audit rubric) and [audits](../spec/systems/guardrails/audits.md) (posture law 3's doc-probe judges register against the rubric). **Carrier (non-locked, authored this pass):** [glossary](../reference/glossary.md) (the canonical *Operator-communication law* definition gains the register clause). **Verify-no-edit (confirm at the landed-text audit):** [surfaces/check](../spec/systems/surfaces/check.md) (its `message` standard already says "never written only for an engineer" and cites the law by reference — it inherits the sharpened rubric without restating it; the register clause lands on *docs* via the probe, bounding blast radius), [validation](../spec/systems/guardrails/validation.md) (mechanical checks judge presence/structure, never prose register — unchanged). **Build-owes:** rewrite `docs/getting-started.md` to the sharpened law. The re-locks land under the **Resolve** entry ([D-216](0216-resolve-the-d-215-operator-prose-register-re-litigation-land.md)) after the mandatory landed-text cold audit.

## Why

The litigation-alarm protocol authorizes a locked-doc change on explicit operator approval. The gap is real and the operator's framing is precise: the doc is a build miss, but the *reason a miss could ship silently* is that the only doc-quality enforcement never looked at register. Sharpening the law **and** routing it into the probe converts a posture the build ignored into a judged standard the audit applies — which is what makes the change worth a locked-doc edit rather than cosmetic churn (the plan-audit's redundancy objection dissolves once the clause is the probe's rubric, not a paraphrase of an existing line). The clause is a *bounded amendment to an existing law* on the operator's explicit, audited call — the legitimate path for a new register standard ([D-192](0192-authorize-the-conduct-surface-codes-of-conduct-a-tier-3-pros.md) mis-promotion rubric: a corpus law is the operator's deliberate call, not a session generalizing a quirk).

## What we ruled out

**Sharpen the law's wording only, no audit teeth** (rejected — the plan-audit's "words the build ignores" objection; the existing "never dumbed down" was already ignored, and longer words change nothing without enforcement). **File the build-owes only, no law edit** (rejected — the operator's call; without the rubric the probe has no register standard to judge against, so the next condescending doc ships the same way). **A new mechanical prose-register check** (rejected — register is a judgment, not a mechanical property; [validation](../spec/systems/guardrails/validation.md) judges presence/structure, the audit judges register, the honest tiers [§7](../principles.md)). **Also edit the [check surface](../spec/systems/surfaces/check.md) `message` standard this pass** (rejected — check inherits the law by reference and already gestures at register; editing it widens the blast radius for no gain, revisitable if the landed-text audit argues the probe should cover check messages too). **Treat the condescending doc as a one-off to fix in place** (rejected — the operator escalated it precisely because the standard had no teeth; the durable fix is the rubric+probe, not just the rewrite).

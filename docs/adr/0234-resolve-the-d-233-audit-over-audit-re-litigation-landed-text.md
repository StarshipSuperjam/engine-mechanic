# Resolve the D-233 audit-over-audit re-litigation: landed-text cold re-check clean, [audits](../spec/systems/guardrails/audits.md) + [audit-library](../spec/modules/audit-library.md) re-locked

*Decided 2026-06-22 in the design workspace.*

## The decision

The [D-233](0233-authorize-the-audit-over-audit-re-litigation-feed-the-period.md) changes landed in the two locked docs and the propagation set ([glossary](../reference/glossary.md) Audits + Audit-digest entries; [risks](../reference/risks.md) R6), and both docs are **re-locked**. **(1) [audits](../spec/systems/guardrails/audits.md):** the new *"Reading its own prior digests — over-time corroboration"* section (all four guardrails — corroborates-never-decides, observed-conditions-only-never-own-prior-judgment, prioritization-computes-nothing, honest-degradation — plus the no-new-artifact/no-ledger/ladder-untouched framing); the module-fit seed-concern reworded to make absence-of-evidence the trigger for the affirmative case, never the proof of disuse; the digest operator-contract gains the fresh-probe-vs-corroborating-history separation requirement; the consent paragraph gains the operator decline-respect (recurrence re-presents the case, never escalates the ask). **(2) [audit-library](../spec/modules/audit-library.md):** one load-bearing scheduled-run grammar bullet — the run must read the committed digest's own prior history (a same-repo read needing no auth beyond the own-repo workflow token; the vehicle — token-free local-`git` from a full-history checkout, the default being shallow, vs. a `gh`-API read — a build-spec leaf; degrade where a clone carries no history). The two logged rejections were honored verbatim: the judgment-ladder gloss and all telemetry phrasing untouched, and the audits never-appears backstage-vocabulary enumeration NOT extended. `python3 lock.py --relock systems/guardrails/audits/README.md --decision D-234`; `python3 lock.py --relock modules/audit-library/README.md --decision D-234`; `python3 validate.py` green.

## Why

A **focused two-lens cold landed-text re-check** (faithfulness + adversarial/technical, no shared context) ran against the on-disk edits — the proportionate close after the plan-stage four-lens audit ([D-148](0148-lock-audit-library-the-engine-self-audit-delivery-the-tenth.md)/[D-230](0230-resolve-the-d-229-audit-auth-correction-landed-text-cold-aud.md) precedent). **Both returned clean:** faithfulness confirmed all four [D-233](0233-authorize-the-audit-over-audit-re-litigation-feed-the-period.md) changes and both rejections landed exactly, no more no less, with no authoring-rule-1 changelog cruft; adversarial/technical confirmed no second committed artifact (telemetry's *"the one committed observational artifact is the audit digest"* preserved — the over-time input reads that same digest's git history), law 2 intact and uncontradicted, no implied ledger ([D-040](0040-telemetry-designed-end-state-native-signal-of-record-tracked.md) stands), the prioritization/corroboration language on the correct side of the [Q17](../reference/open-questions.md)/[§12](../principles.md) deferral line, and Change 3 technically coherent and consistent with the locked module doc's own-repo-token / cross-repo-memory-backup framing. Only non-blocking nits surfaced, none requiring an edit before the re-lock.

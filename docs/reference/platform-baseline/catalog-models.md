  Anthropic never updates weights of an existing ID — an updated version ships under a new ID.

  matches the Claude API for dateless IDs and separates dates with @. Every ID (dated or dateless)

  surrounding serving infrastructure (router, safety classifiers, sampling) can change and
  occasionally alters observable behavior. The overview page's alias column is the documented set
